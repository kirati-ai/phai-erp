# ติดตั้ง PhaiERP

## สิ่งที่ต้องมี

| | |
|---|---|
| PHP | 8.2 ขึ้นไป พร้อม `pdo_mysql`, `mbstring` (และ `curl` ถ้าจะใช้ AI) |
| ฐานข้อมูล | MySQL 8.0+ หรือ MariaDB 10.6+ |
| เว็บเซิร์ฟเวอร์ | Apache (เปิด `mod_rewrite`) หรือ Nginx |

ไม่ต้องใช้ Composer, npm หรือขั้นตอน build

## 1. วางไฟล์

**แบบง่าย (Apache)** — คัดลอกโฟลเดอร์ `phai-erp` ไปไว้ใต้ web root เช่น `htdocs/phai-erp` แล้วเปิด `http://localhost/phai-erp/`
ไฟล์ `.htaccess` ที่โฟลเดอร์หลักส่งทุกคำขอเข้า `public/` จึงไม่มีใครเปิดอ่าน `config.php`, `src/` หรือ `database/` ได้

**แบบแนะนำสำหรับเครื่องจริง** — ชี้ document root ไปที่ `phai-erp/public` โดยตรง

Nginx:

```nginx
server {
    listen 80;
    server_name erp.example.com;
    root /var/www/phai-erp/public;
    index index.php;

    location / {
        try_files $uri /index.php$is_args$args;
    }
    location ~ \.php$ {
        include fastcgi_params;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        fastcgi_pass unix:/run/php/php8.2-fpm.sock;
    }
}
```

ให้เว็บเซิร์ฟเวอร์เขียนได้ที่ `storage/logs`, `storage/uploads` และ (ระหว่างติดตั้ง) โฟลเดอร์หลัก เพื่อสร้าง `config.php`

## 2. หน้าติดตั้ง

เปิดเว็บครั้งแรก ระบบจะไปหน้า `/install` เอง เป็นขั้นตอน 5 ขั้น กด **ถัดไป** / **ย้อนกลับ** ได้ ทุกขั้นถูกตรวจก่อนไปขั้นถัดไป และยังไม่มีอะไรถูกสร้างจนกว่าจะกดติดตั้งในขั้นสุดท้าย

1. **ตรวจเครื่อง** — รายการสิ่งที่ต้องมีต้องเป็นสีเขียว
2. **ฐานข้อมูล** — ระบบทดสอบการเชื่อมต่อให้เมื่อกดถัดไป ใช้ฐานข้อมูลใหม่หรือฐานข้อมูลว่าง ถ้ายังไม่มีระบบจะสร้างให้
3. **บริษัท** — ชื่อ เลขผู้เสียภาษี โทรศัพท์ ที่อยู่ (เลือกจังหวัด อำเภอ ตำบล รหัสไปรษณีย์เติมให้ — ใส่ไม่ครบก็ได้) และ **โลโก้** (คลิกหรือลากรูป PNG, JPG, WebP ไม่เกิน 1 MB) — โลโก้แสดงบนหน้าเข้าสู่ระบบและเอกสารพิมพ์ ที่อยู่และโลโก้แก้ภายหลังได้ที่ **ตั้งค่าระบบ › ข้อมูลบริษัท**
4. **ผู้ดูแลระบบ** — รหัสผ่านอย่างน้อย 8 ตัว พิมพ์ซ้ำเพื่อยืนยัน
5. **ยืนยัน** — ตรวจสรุป ติ๊ก **ใส่ข้อมูลตัวอย่างสำหรับทดลอง** ถ้าต้องการ (ดูหัวข้อถัดไป) แล้วกด **ติดตั้ง** เสร็จแล้วกดไปหน้าเข้าสู่ระบบ

ถ้าเขียน `config.php` ไม่ได้ หน้าติดตั้งจะแสดงข้อความให้คัดลอกไปบันทึกเป็นไฟล์ `config.php` ในโฟลเดอร์หลักเอง

ติดตั้งใหม่: ลบ `config.php` และฐานข้อมูล แล้วเปิดเว็บอีกครั้ง

## 3. ข้อมูลตัวอย่าง

ข้อมูลตัวอย่างแบบโรงงานผลิตชั้นวางและโต๊ะเหล็ก ย้อนหลัง 2 เดือน (ข้อมูลบริษัทของคุณไม่ถูกแก้): ทุกเมนูมีข้อมูล — สินค้า กลุ่ม/ประเภทสินค้า ราคาขาย อัตราแลกเปลี่ยน คลังที่สอง สูตรการผลิต ผู้ขาย ลูกค้า (ที่อยู่แยกช่อง เลขผู้เสียภาษีสมมติ) ใบขอซื้อ ใบสั่งซื้อ รับสินค้า (มีใบที่รอตั้งหนี้ และค่าใช้จ่ายนำเข้า) ตั้งหนี้ ใบสำคัญจ่าย จ่ายชำระ (50 ทวิ หักสองอัตรา 1% และ 3%) ใบสั่งผลิต QC ขาย ส่งของ ใบแจ้งหนี้ ใบรับคืนสินค้าและใบลดหนี้ ใบส่งคืนสินค้า ใบวางบิล รับชำระ สมุดรายวัน กระทบยอดธนาคาร ผล MRP ภ.พ.30 สองเดือนที่ปิดงวด และใบตรวจนับที่ยังนับอยู่
ทุกรายการสร้างผ่าน API เดียวกับหน้าจอ ยอดสต็อก ต้นทุน และบัญชีจึงถูกต้องเหมือนใช้งานจริง ชื่อทั้งหมดเป็นชื่อสมมติ

ใส่ภายหลังได้ (เฉพาะระบบที่ยังไม่มีสินค้า) ใส่แล้ว **อยู่ถาวร ลบออกไม่ได้** — ถ้าต้องการระบบว่าง ให้ติดตั้งใหม่ (ลบ `config.php` และฐานข้อมูล แล้วเปิดหน้าติดตั้ง):

```bash
php bin/phai demo
```

## 4. ค่าใน config.php

| ค่า | ความหมาย |
|---|---|
| `app.url` | ที่อยู่เว็บ (หน้าติดตั้งตั้งให้) |
| `app.debug` | `false` เสมอบนเครื่องจริง — ถ้า `true` จะแสดงรายละเอียด error |
| `app.timezone`, `app.locale` | เขตเวลา, ภาษาเริ่มต้น (`th` / `en`) |
| `db.*` | การเชื่อมต่อฐานข้อมูล |
| `session.lifetime` | นาทีที่ไม่ใช้งานก่อนต้องเข้าสู่ระบบใหม่ |
| `ai.*` | ผู้ให้บริการ AI, key, รุ่น, ราคา — ตั้งในหน้า **ตั้งค่าระบบ › ตั้งค่า AI** ได้ |
| `pdf.browser` | Edge หรือ Chrome ที่ใช้สร้างไฟล์ PDF — เว้นว่างให้ระบบหาเอง (ไม่มีเบราว์เซอร์ = ใช้ "บันทึกเป็น PDF" จากหน้าต่างพิมพ์แทน) |

`config.php` มีรหัสผ่านฐานข้อมูลและ API key — อย่า commit และอย่าเปิดให้ดาวน์โหลด

## 5. ใช้งานจริง

- ใช้ HTTPS (cookie ของระบบจะตั้ง `Secure` ให้เองเมื่อเปิดผ่าน HTTPS)
- สร้างผู้ใช้ฐานข้อมูลเฉพาะ ให้สิทธิ์แค่ฐานข้อมูลของ PhaiERP
- สำรองข้อมูลทุกวัน:

```bash
mysqldump --single-transaction --routines phaierp > phaierp-$(date +%F).sql
```

  และสำรอง `config.php` กับ `storage/uploads`

- อัปเดตรุ่น: สำรองฐานข้อมูลและไฟล์ก่อน แทนที่ไฟล์โปรแกรมทั้งหมดยกเว้น `config.php` และ `storage/` แล้วอ่าน [CHANGELOG.md](../CHANGELOG.md) ว่ามีการเปลี่ยนโครงสร้างฐานข้อมูลหรือไม่

## คำสั่งบรรทัดคำสั่ง

```bash
php bin/phai version
php bin/phai demo
php bin/phai password admin   # ลืมรหัสผ่าน: ตั้งรหัสใหม่ (และปลดล็อก)
php tests/run.php
```
