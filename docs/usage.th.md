# คู่มือการใช้งาน PhaiERP

ภาพรวมของระบบ — ERP คืออะไร แต่ละโมดูลเชื่อมกันอย่างไร เอกสารในแต่ละสาย ชื่อทางราชการ และรายการบัญชี — อยู่ในเมนู **เรียนรู้ ERP** ใต้หน้าแรก ทุกหน้าจอมีปุ่ม **ช่วยเหลือ** ขวาบนที่บอกว่าเอกสารนั้นมาจากไหน ไปต่อที่ไหน

เมนูด้านซ้ายเรียงตามลำดับงาน: ข้อมูลหลัก → จัดซื้อ → คลังสินค้า → ผลิต → ขาย → บัญชี และตั้งค่าระบบ — ทุกหมวดเริ่มด้วยหน้าภาพรวม (ถ้ามี) — แถวบนสุดของหน้าภาพรวมเป็นการ์ดของทุกหน้าในส่วนทำรายการ บอกว่าหน้านั้นทำอะไร และมีเอกสารใดรออยู่ (เลขที่ 3 ใบแรก) — แล้วมีสองหัวข้อ: **ตั้งค่า** (ข้อมูลที่ต้องกำหนดก่อนใช้) อยู่บน (พับไว้ คลิกหัวข้อเพื่อเปิด เบราว์เซอร์จำไว้ และเปิดเองเมื่ออยู่ในหน้าตั้งค่า) และ **ทำรายการ** (เอกสาร สอบถาม รายงาน) อยู่ล่าง — หมวดบัญชีแบ่งส่วนทำรายการเป็น เจ้าหนี้ (AP) ลูกหนี้ (AR) บัญชีแยกประเภท (GL) และสินทรัพย์ถาวร (FA) (ขายเห็น **สต็อกสินค้า** FG, จัดซื้อและผลิตเห็น **สต็อกวัตถุดิบ** RM) ผู้ใช้เห็นเฉพาะเมนูที่บทบาทของตนมีสิทธิ์

**คิวงาน:** หน้าเอกสารแสดงงานที่ขั้นก่อนหน้าส่งมารอไว้เหนือรายการ (ไม่มีงานรอก็ไม่แสดง) แต่ละแถวมีปุ่มทำต่อที่เปิดเอกสารใหม่ซึ่งเติมข้อมูลไว้ให้ บางคิวติ๊กหลายแถวของรายเดียวกันแล้วทำเป็นเอกสารเดียวได้ แถวสีแดง = เลยกำหนด — ขาย: ใบเสนอราคารอเปิดใบสั่งขาย → ใบสั่งขายรอส่งของ (ทีละบรรทัด: ส่งที่ มีของพอไหม ขาดแล้วรอใบสั่งผลิต/ใบสั่งซื้อใบไหน ส่งได้วันไหน) → ใบส่งของรอออกใบแจ้งหนี้ → ใบแจ้งหนี้รอวางบิล; จัดซื้อ: MRP แนะนำให้ซื้อ → ใบขอซื้อรอสั่งซื้อ → ใบสั่งซื้อรอรับ → ใบรับนำเข้ารอใส่ค่าใช้จ่าย; บัญชี: ใบรับรอตั้งหนี้ → ตั้งหนี้รอใบสำคัญจ่าย → ใบสำคัญจ่ายรอจ่าย, ลูกหนี้รอรับชำระ, เอกสารรอส่ง e-Tax, ธนาคารรอกระทบยอด, งวดรอปิด, สินทรัพย์รอขึ้นทะเบียนและค่าเสื่อมรอลงบัญชี; ผลิต: แผน MRP รอเปิดใบสั่งผลิต → ใบสั่งผลิตรอเริ่มผลิต; คลัง: ใบตรวจนับที่ยังไม่ปรับยอด — กล่องคิวมีกรอบสีส้ม คลิกแถวเปิดเอกสารนั้นในหน้าต่างเพื่อดูอย่างเดียว

**รายการเอกสาร** แสดงทีละเดือนตามวันที่เอกสาร เริ่มที่เดือนนี้ ปุ่ม ‹ › เลื่อนเดือน หรือเลือกเดือนในช่อง ลบช่องเดือนให้ว่างเพื่อดูทุกเดือน — เปิดหน้าด้วย `?month=2026-09` เพื่อไปเดือนนั้นได้ ในหน้าแก้ไขเอกสารมีปุ่ม **ยกเลิก** ข้างบันทึก เพื่อทิ้งสิ่งที่แก้

## การใช้งานทั่วไป

- **หน้าแรก** ภาพรวมสำหรับผู้บริหาร (อ่านอย่างเดียว ไม่มีลิงก์): เงินสดในธนาคาร ยอดขายและกำไรขั้นต้นเดือนนี้ กำไรสุทธิตั้งแต่ต้นปี ยอดสั่งขายรอส่ง ลูกหนี้ เจ้าหนี้ มูลค่าสินค้าคงเหลือ กราฟยอดขายและ % กำไรขั้นต้น 12 เดือน (เทียบปีก่อน) อายุลูกหนี้ กระแสเงินสดคาดการณ์ 8 สัปดาห์ ภาษีที่ต้องยื่นและงวดบัญชี เรื่องที่ต้องดู (ลูกหนี้เกินกำหนด เกินวงเงิน สินค้าต่ำกว่าจุดสั่งซื้อ ส่งของ/ผลิต/ผู้ขายล่าช้า) และลูกค้ายอดขายสูงสุดพร้อมกำไร — ปุ่ม **ส่งออก PDF** ได้หน้านี้เป็น A4 แนวนอน แต่ละคนเห็นเฉพาะส่วนที่มีสิทธิ์
- เมนูซ้ายย่อเหลือไอคอนได้ด้วยปุ่มสามขีดหรือปุ่มย่อเมนูด้านล่าง

- หน้ารายการ: ช่องค้นหา (กด `/` เพื่อไปที่ช่องค้นหา) ตัวกรองสถานะ คลิกหัวคอลัมน์เพื่อเรียง คลิกแถวเพื่อเปิด ท้ายแถวมีไอคอน 5 ตัวเสมอ: ดู (หน้าอ่านอย่างเดียว) พิมพ์ แก้ไข ยกเลิก (กลับรายการ) ลบ ตัวที่ทำไม่ได้กับแถวนั้นหรือไม่มีสิทธิ์จะจางและคลิกไม่ได้
- บันทึกด้วยปุ่ม **บันทึก** หรือ Enter ข้อผิดพลาดแสดงใต้ช่องที่ผิด
- หน้าสร้างเอกสารใหม่แสดงเลขที่ที่จะได้ไว้ข้างชื่อหน้า (เช่น PO2026100005) เลขยังไม่ถูกจองจนกดบันทึก ถ้าออกจากหน้าโดยไม่บันทึก เลขนั้นยังเป็นของเอกสารถัดไป
- ช่องที่เลือกจากข้อมูล (ลูกค้า ผู้ขาย สินค้า เลขที่เอกสาร ล็อต) คลิกแล้วมีรายการให้เลือก พิมพ์เพื่อค้นหา เลือกด้วยลูกศร + Enter หรือคลิก
- ระบบถามยืนยันเฉพาะการกระทำที่ย้อนกลับไม่ได้ เช่น ลบ ยกเลิก ปิดงวด
- เอกสารพิมพ์เป็น A4 พร้อมโลโก้จากปุ่ม **พิมพ์** (ใบสั่งซื้อ ใบเสนอราคา ใบส่งของ ใบแจ้งหนี้/ใบกำกับภาษี ใบวางบิล ใบเสร็จ ใบสำคัญจ่าย 50 ทวิ) ปุ่ม **บันทึก PDF** ให้ไฟล์ PDF ชื่อตามเลขที่เอกสาร — หัวเอกสารมีชื่อเอกสารและเลขที่มุมขวา ลูกค้า/ผู้ขายคู่กับกรอบรายละเอียดเอกสาร ตารางรายการยาวลงไปถึงยอดรวม และแถวช่องลงนามท้ายหน้า
- **ลายเซ็นในเอกสาร** (ทุกเอกสารที่พิมพ์): ตั้งลายเซ็นครั้งเดียวที่เมนูชื่อผู้ใช้ → **ลายเซ็นของฉัน** (เซ็นด้วยเมาส์หรือนิ้ว หรืออัปโหลดรูปถ่ายลายเซ็นบนกระดาษขาว ระบบตัดขอบและทำพื้นใสให้ เก็บเป็น PNG ไม่เกิน 600 × 200 จุด พิมพ์กว้างไม่เกิน 4 ซม.) แล้วกดปุ่ม **ลายเซ็น** ข้างปุ่มพิมพ์ของเอกสาร ใต้แต่ละช่องลงนามมีปุ่ม **เซ็น** / **ขอลายเซ็น** / **ไม่อนุมัติ** / **ถอนลายเซ็น** ตามสิทธิ์ — ช่องของเรา (ผู้จัดทำ ผู้ส่งสินค้า ผู้รับเงิน) ผู้มีสิทธิ์พิมพ์เอกสารนั้นเซ็นเองได้ ช่องอนุมัติ (ผู้อนุมัติ ผู้ตรวจสอบ ผู้มีอำนาจลงนาม) เซ็นได้เฉพาะคนที่ถูกขอให้เซ็นหรือ ADMIN ช่องของลูกค้า/ผู้ขายเว้นไว้เซ็นบนกระดาษ — **ขอลายเซ็น** เลือกได้เฉพาะคนที่มีสิทธิ์เปิดเอกสารนั้น คำขอขึ้นที่ **รอฉันเซ็น** (แถบบนและหน้า **เอกสารรอเซ็น**) และส่งอีเมลพร้อมลิงก์เมื่อตั้งค่าอีเมลไว้ (หน้าตั้งค่า e-Tax) — เปิดลิงก์แล้วต้องเข้าสู่ระบบก่อนเสมอ เซ็นแล้วลายเซ็น ชื่อ วันที่ขึ้นในใบพิมพ์และ PDF ทันที พร้อม **ตราประทับบริษัท** (ตั้งที่หน้าข้อมูลบริษัท พิมพ์เฉพาะเอกสารที่ส่งให้ลูกค้า/ผู้ขายซึ่งเซ็นแล้ว) แก้เอกสารหลังเซ็น ลายเซ็นไม่แสดงจนกว่าจะเซ็นใหม่ ระบบจดว่าใครเซ็น เมื่อไร จากเครื่องไหน และเก็บสำเนารูปลายเซ็นไว้กับเอกสาร (เปลี่ยนลายเซ็นภายหลังไม่กระทบเอกสารเก่า) — ลายเซ็นรูปนี้ไม่ใช่ลายมือชื่อดิจิทัลของ e-Tax ซึ่งยังลงนามด้วยใบรับรองตามเดิม
- ตัวเลขเงินแสดงทศนิยม 2 ตำแหน่ง วันที่แสดงแบบ วว/ดด/ปปปป
- **เอกสารแนบ** (รูปหรือ PDF หลายไฟล์ รูปถูกย่อก่อนส่ง): ใบขอซื้อ ใบสั่งซื้อ ใบรับสินค้า ค่าใช้จ่ายนำเข้า ใบส่งคืนสินค้า ใบสั่งขาย ใบส่งของ ใบรับคืนสินค้า ตั้งหนี้ จ่ายชำระ รับชำระ สมุดรายวัน กระทบยอดธนาคาร (Statement) ภ.พ.30 ที่ยื่นแล้ว รายงาน ภ.ง.ด. ใบตรวจนับ ทะเบียนสินทรัพย์ เงินสดย่อย และในหน้าต่างของผู้ขาย ลูกค้า สินค้า QC — หัวข้อ **เอกสารแนบ** ใต้เอกสารที่บันทึกแล้ว บอกว่าควรแนบอะไร (เช่น ใบสั่งขาย: PO ของลูกค้า, ตั้งหนี้: ใบกำกับภาษีของผู้ขาย) และทุกตารางของเอกสารเหล่านี้มี **รูปคลิปท้ายแถว** กดแล้วเปิดหน้าต่างดู แนบ ลบไฟล์ของแถวนั้นได้เลย (คลิปสีเขียวพร้อมตัวเลข = จำนวนไฟล์) สิทธิ์ตามหน้าจอนั้น (ดู = เปิดไฟล์, เพิ่ม/แก้ไข = แนบ, แก้ไข/ลบ = ลบไฟล์) ลบเอกสารแล้วไฟล์แนบถูกลบด้วย — เงินสดย่อยแนบ/ลบได้เฉพาะผู้ถือในเดือนที่ยังไม่นับ

## เริ่มต้นตั้งค่า

1. **ตั้งค่าระบบ › ข้อมูลบริษัท** — ชื่อ ที่อยู่แยกช่องตามแบบฟอร์มกรมสรรพากร (เลขที่ หมู่ที่ อาคาร ชั้น ห้อง หมู่บ้าน ซอย แยก ถนน และที่อยู่เพิ่มเติม — ระบบประกอบเป็นบรรทัดเดียวสำหรับเอกสาร; จังหวัด อำเภอ ตำบล เลือกจากรายชื่อจังหวัด อำเภอ ตำบล) โลโก้ เลขผู้เสียภาษี สาขา (ใช้บนเอกสารพิมพ์) และเวลาออกจากระบบเมื่อไม่ใช้งาน (นาที, 0 = ไม่ออก)
2. **ตั้งค่าระบบ › ตั้งค่าเลขที่เอกสาร** (หรือตารางท้ายหน้าตั้งค่าของแต่ละหมวด เฉพาะเอกสารของหมวดนั้น) — คำนำหน้า รูปแบบ และเลขถัดไปของแต่ละเอกสาร ค่าเริ่มต้นคือ ปีเดือน + 4 หลัก เช่น `PO2026100001` เริ่ม 0001 ใหม่ทุกเดือน (เลือกแบบ ปี + 5 หลัก หรือเลข 6 หลักไม่เริ่มใหม่ได้)
3. **ตั้งค่าระบบ › ตั้งค่าบัญชี** — งวดบัญชีที่เปิด และบัญชีตั้งต้น (ลูกหนี้ เจ้าหนี้ ขาย ต้นทุนขาย สินค้า ภาษีซื้อ/ขาย ฯลฯ)
4. **ข้อมูลหลัก** — สินค้าและวัตถุดิบ สายผลิตภัณฑ์ กลุ่ม ประเภท หน่วยนับ สกุลเงินและอัตราแลกเปลี่ยน ภาษี เงื่อนไขชำระเงิน; ข้อมูลเฉพาะแผนกอยู่ต้นหมวดของแผนกนั้น เช่น **จัดซื้อ › ผู้ขาย**, **คลังสินค้า › คลังและตำแหน่งเก็บ**, **ผลิต › ศูนย์งาน เครื่องจักร**, **ขาย › ลูกค้า**, **บัญชี › ผังบัญชี** — ที่อยู่ลูกค้า ผู้ขาย และสาขา/คลัง (ตั้งค่าระบบ › สาขา แท็บที่อยู่) กรอกแยกช่องแบบเดียวกับที่อยู่บริษัท (เลขที่ หมู่ที่ อาคาร ชั้น ห้อง หมู่บ้าน ซอย แยก ถนน ที่อยู่เพิ่มเติม) ระบบประกอบเป็นบรรทัดเดียวบนเอกสาร — ช่องที่เอกสารถัดไปต้องใช้ บังคับกรอก: ผู้ขาย/ลูกค้าในประเทศต้องมีเลขผู้เสียภาษี 13 หลัก สาขา 5 หลัก จังหวัด อำเภอ ตำบล รหัสไปรษณีย์ (ใช้ในใบกำกับภาษี 50 ทวิ ภ.ง.ด. รายงานภาษี และ e-Tax) และเงื่อนไขชำระเงิน สกุลเงิน ภาษี (ใช้คิดวันครบกำหนด สกุลเงิน VAT ของเอกสาร) ผู้ขาย/ลูกค้าต่างประเทศไม่ต้องมีเลขผู้เสียภาษีและที่อยู่แบบไทย; รหัสหัก ณ ที่จ่ายต้องมีบัญชี
5. **ตั้งค่าระบบ › บทบาทและสิทธิ์** แล้ว **ผู้ใช้** — กำหนดสิทธิ์ ดู เพิ่ม แก้ ลบ พิมพ์ ต่อหน้าจอ (สิทธิ์ แก้ รวมการกระทำสำคัญ เช่น ปรับยอดตรวจนับ ปิดงวด)

ตรวจนับสต็อกใช้ **ป้ายตรวจนับ** (PI Tag): สร้างใบตรวจนับ เลือก **ขอบเขตการนับ** ทั้งคลัง (นับสิ้นปี) หรือเลือกตำแหน่ง (นับหมุนเวียน — ล็อกเฉพาะตำแหน่งที่เลือก) แล้วกด **พิมพ์ป้าย** (หน้าละ 8 ใบ ไม่มียอดระบบ) แขวนทุกกอง คนนับเขียนจำนวนและลงชื่อ เก็บป้ายกลับมากรอกพร้อมช่อง **ผู้นับ** — ป้ายที่ไม่ใช้กด **ยกเลิกป้าย** (ยังอยู่ในรายการ เลขป้ายครบเสมอ) ป้ายที่ต่างมากกด **นับซ้ำ** (เก็บผลนับครั้งแรกไว้) ปรับยอดได้เมื่อทุกป้ายนับแล้วหรือยกเลิก ไม่ครบระบบบอกเลขป้ายที่ขาด

ยอดสต็อกยกมาใช้ **คลังสินค้า › ตรวจนับสต็อก**: สร้างใบตรวจนับของคลังนั้น เลือกเหตุผล `OPEN` แล้วเพิ่มของที่มีทีละบรรทัด (ตำแหน่ง สินค้า ล็อต จำนวน ต้นทุน/หน่วย — ล็อตว่างใช้เลขใบตรวจนับ) แล้วกด **ปรับยอดตามผลนับ** สต็อกเข้าที่ต้นทุนที่ใส่ และลงบัญชีกับกำไรสะสม

## คลังสินค้า

- **สินค้าและวัตถุดิบ** — หน้าเดียว กรองตามประเภท (FG/RM ตามสายผลิตภัณฑ์) และสายผลิตภัณฑ์
- **ยอดคงเหลือ** — ตามคลัง ตำแหน่ง และล็อต หรือรวมต่อสินค้า กรองตามประเภทและสายผลิตภัณฑ์ได้ (เมนู **สต็อกสินค้า** / **สต็อกวัตถุดิบ** ในแผนกขาย จัดซื้อ ผลิต เปิดหน้านี้โดยกรองไว้ให้) — คลิกแถวเพื่อเปิดหน้าดูของแถวนั้น: สินค้า คลัง ตำแหน่ง ล็อต ล็อตผู้ขาย วันหมดอายุ คงเหลือ จองแล้ว ต้นทุน/หน่วย มูลค่า และประวัติความเคลื่อนไหวของคลัง ตำแหน่ง และล็อตนั้น (โหมดรวมต่อสินค้าคลิกไม่ได้; หน้าสต็อกที่เปิดจากเมนูจัดซื้อ ขาย หรือผลิต แสดงแถวในหน้าต่าง ไม่ย้ายไปหน้าคลังสินค้า) ปุ่มในหน้าดู: **แปลงเป็น FG** (วัตถุดิบ), **โอนย้าย** (ระบุจำนวน คลังและตำแหน่งปลายทาง มูลค่าที่ย้าย = จำนวน × ต้นทุน/หน่วยของแถว ล็อตและวันหมดอายุตามไป) และ **แก้ไข** (อ้างอิง S/N หรือพาเลต, จำนวนต่อแพ็ค, สถานะ เกรด วันที่รับเข้า วันหมดอายุ และเลขล็อต — สินค้าที่ยังไม่คุมล็อต ใส่ล็อตแล้วสินค้าจะเปลี่ยนเป็นคุมล็อต (ต่อไปส่งของ/เบิก/โอนต้องเลือกล็อต) แถวที่ยังไม่มีล็อตใส่ล็อตแล้วยอดทั้งแถวย้ายเข้าล็อตนั้น สินค้าคุมล็อตแก้ล็อตผู้ขายและหมายเหตุล็อตได้ด้วย เลขล็อตเปลี่ยนทุกที่ที่อ้างถึง และวันหมดอายุ/ล็อตผู้ขาย/หมายเหตุใช้กับทุกตำแหน่งของล็อตนั้น; คลังและตำแหน่งเปลี่ยนด้วยโอนย้าย; จำนวนและต้นทุนแก้ไม่ได้ ต้องทำผ่านการเคลื่อนไหว)
- ล็อตมาจากการรับเสมอ: รับจากใบสั่งซื้อ = เลขที่ใบกำกับภาษี, รับจากใบสั่งผลิต = เลขใบสั่งผลิต, รับเข้าเอง = เลขที่เอกสารรับ (พิมพ์ทับได้) — เบิกออกเลือกได้เฉพาะล็อตที่มีสต็อก (ไม่มีปรับยอด: ลดยอดใช้เบิกออกพร้อมรหัสเหตุผล เพิ่มยอดใช้รับเข้า)
- หน้าสต็อกมีปุ่ม **ปรับราคา** (สินค้า FG) — ไม่มีปุ่มรับเข้า/เบิกออกแล้ว ของเข้ามาจากใบรับสินค้า ใบสั่งผลิต หรือการตรวจนับ
- **ปรับราคา** (เฉพาะสินค้า FG วัตถุดิบใช้ราคาที่รับเข้า): เลือกสินค้าและราคาใหม่ ทุกตำแหน่ง/ล็อตที่มีสต็อกจะออกด้วยราคาเดิมและเข้าด้วยราคาใหม่ (จำนวนไม่เปลี่ยน)
- **แปลงเป็น FG** (ปุ่มในหน้าดูของแถววัตถุดิบ): วัตถุดิบขายตรงไม่ได้ (หลักซื้อมาขายไป) ต้องแปลงเป็นสินค้า FG ก่อน — ระบุจำนวนวัตถุดิบ สินค้า FG ที่ได้ จำนวน และตำแหน่งที่เก็บ ต้นทุน FG = มูลค่าวัตถุดิบที่ใช้
- ทุกการเคลื่อนไหวบันทึกใน **ประวัติความเคลื่อนไหว** แต่ละแถวมี ยอดก่อน, จำนวนที่เปลี่ยน (+ รับ / − จ่าย) และคงเหลือหลังทำรายการของคลัง ตำแหน่ง และล็อตนั้น (เช่น 0 +80 = 80 แล้ว 80 −30 = 50) และลงบัญชีให้เอง
- สินค้าที่ไม่ได้ติ๊ก **เก็บสต็อก** (ค่าบริการ วัสดุสิ้นเปลือง เครื่องจักรที่จะขึ้นทะเบียนสินทรัพย์) ไม่มียอดคงเหลือและไม่ลงประวัติความเคลื่อนไหว
- **ตรวจนับสต็อก** — สร้างรอบนับ บันทึกยอดนับ (ระบบเทียบกับยอดในระบบขณะกรอก ของที่เข้าออกระหว่างรอนับจึงไม่เป็นผลต่าง) แล้วยืนยันเพื่อปรับยอด
- **รายงานสินค้าและวัตถุดิบ** (ม.87(3)): ช่องสินค้าว่าง = ทุกสินค้าที่มียอดหรือมีความเคลื่อนไหว แยกเป็นกลุ่มทีละสินค้า (เลือกสินค้าเดียว ประเภท FG/RM คลัง เดือน หรือช่วงวันที่ได้) แต่ละสินค้าได้ยอดยกมา ทุกรายการรับ/จ่าย และคงเหลือสะสมทั้งจำนวนและมูลค่า พิมพ์ A4 แนวนอน — ท้ายรายงานมีมูลค่ารวมทุกสินค้า (ใช้เทียบบัญชีสินค้าคงเหลือ)
- ต้นทุนเป็นแบบถัวเฉลี่ย คำนวณใหม่ทุกครั้งที่รับเข้า สต็อกติดลบไม่ได้ (เปลี่ยนได้ใน **ตั้งค่าคลังสินค้า**)

## จัดซื้อ

บรรทัดใบขอซื้อ ใบสั่งซื้อ ใบเสนอราคา และใบสั่งขาย เลือกสินค้าจากรายการ หรือพิมพ์รายการที่ไม่มีในระบบเองได้ (เช่น ค่าขนส่ง ค่าติดตั้ง) โดยใส่รายละเอียดและหน่วยเอง รายการที่พิมพ์เองและสินค้าไม่เก็บสต็อก รับของ/ส่งของโดยไม่ต้องเลือกตำแหน่ง ไม่เข้าออกสต็อก ฝั่งซื้อลงบัญชีค่าใช้จ่าย (บัญชีซื้อของสายผลิตภัณฑ์ หรือ **ค่าใช้จ่ายรายการไม่เก็บสต็อก** ในตั้งค่าบัญชี)

```
ใบขอซื้อ → ใบสั่งซื้อ → รับสินค้า (→ ส่งคืนสินค้า) → ตั้งหนี้ → ใบสำคัญจ่าย → จ่ายชำระ → 50 ทวิ → ภ.ง.ด.3/53
```

- **ใบขอซื้อ** ไม่มีขั้นอนุมัติ (เอกสารพิมพ์ไปเซ็น) บันทึกแล้วสร้างใบสั่งซื้อได้ทันที หรือสร้างจากผล MRP — กด **สร้างใบสั่งซื้อ** ที่ใบขอซื้อ ระบบแยกเป็นใบสั่งซื้อตาม **ผู้ขายที่แนะนำ** ของแต่ละบรรทัด บรรทัดที่ไม่ได้ระบุผู้ขายจะถามผู้ขายให้ (ถ้าทุกบรรทัดระบุแล้วจะไม่ถาม)
- **ใบสั่งซื้อ** ราคาไม่รวม VAT รองรับสกุลเงินต่างประเทศ ไม่มีขั้นอนุมัติ บันทึกแล้วรับของได้ทันที แก้ได้เฉพาะก่อนรับของ — เมื่อรับของแล้ว ด้านขวาของใบสั่งซื้อแสดง **ประวัติรับสินค้า** (เลขที่ วันที่ รายการ จำนวน) คลิกเปิดใบรับได้
- **ใบสั่งซื้อ / ใบสั่งขายแบบกำหนดส่ง** (แบบ Supplier / Customer Scheduling ของระบบใหญ่): เลือก **ประเภทใบสั่ง = แบบกำหนดส่ง** (สัญญาราคาระยะยาว ส่งหลายงวด) บันทึกแล้วกด **ตารางกำหนดส่ง** (หรือเมนู **จัดซื้อ › ตารางกำหนดส่งของผู้ขาย** / **ขาย › ตารางกำหนดส่งให้ลูกค้า** ที่รวมทุกใบพร้อมรอบที่ใช้และงวดถัดไป) → **ออกรอบใหม่** (รอบตาราง เลขที่ = วันที่ออก-ลำดับ รอบล่าสุดคือรอบที่ใช้ รอบเก่าเก็บเป็นประวัติ เทียบกับรอบก่อนได้ทุกงวด) ใส่วันที่ออกรอบ **ยืนยันส่งจริงถึง** (งวดถึงวันนั้น = ยืนยันส่งจริง หลังจากนั้น = พยากรณ์ ค่าเริ่มต้น 14 วัน) ที่มา เลขอ้างอิง แล้วแบ่งงวด วันที่ + จำนวน — ฝั่งซื้อกด **ออกรอบใหม่จาก MRP** ได้ (งวดที่ยืนยันแล้วหรือรับของแล้วคงไว้ งวดหลังจากนั้นตามที่ MRP คำนวณ) ฝั่งขายกรอกตามตารางที่ลูกค้าส่งมา (ลูกค้ารายใหญ่ส่งทาง EDI) หรือกำหนดเอง พิมพ์รอบส่งคู่ค้าได้ — จำนวนสั่งของบรรทัดเท่ากับผลรวมงวดของรอบที่ใช้ ที่รับ/ส่งแล้วนับเข้างวดแรกก่อน ครบทุกงวดแล้วใบสั่งยังเปิดอยู่ (ออกรอบเพิ่มงวดได้) จนกด **ปิด** MRP วางแผนตามวันที่ของแต่ละงวด ใบพิมพ์ใบสั่งมีตารางงวดของรอบที่ใช้
- **รับสินค้า** รับบางส่วนได้ รับเกินที่สั่งได้ (เกินเปอร์เซ็นต์ที่ตั้งไว้ขึ้นคำเตือน "รับเกินใบสั่งซื้อ" แต่ยังบันทึก) สินค้าเข้าสต็อกที่ราคาหลังส่วนลด × อัตราแลกเปลี่ยน สินค้าที่คุมล็อตใช้เลขที่ใบกำกับภาษีเป็นล็อตให้เอง (พิมพ์ทับได้) — แต่ละบรรทัดมีช่อง **ต่อแพ็ค** (จำนวนต่อแพ็ค/มัด ค่าเริ่มต้น 1) เก็บไว้กับแถวสต็อกที่รับเข้า ใบรับที่บันทึกแล้วเปิดเป็นหน้าดู (กลับ ป้าย รอตั้งหนี้/ตั้งหนี้แล้ว ปุ่มตั้งหนี้ พิมพ์ / PDF) แก้ไม่ได้ เพราะสต็อกและบัญชีลงไปแล้ว
- **ส่งคืนสินค้า** (ใบส่งคืนสินค้า): เปิดใบรับแล้วกด **ส่งคืนสินค้า** ใส่เหตุผลและจำนวนที่คืน (ไม่เกินที่รับมาลบที่คืนแล้ว) ของออกจากตำแหน่งและล็อตเดิม ลงบัญชี Dr สินค้ารับแล้วรอใบแจ้งหนี้ (ราคาซื้อ) / Cr สินค้า (ต้นทุนเฉลี่ย) — ถ้ายังไม่ตั้งหนี้ ติ๊กใบส่งคืนพร้อมใบรับในหน้าตั้งหนี้ (หักจากใบแจ้งหนี้) ถ้าตั้งหนี้แล้ว บันทึก **ใบลดหนี้** ของผู้ขายจากปุ่มบนใบส่งคืน
- **ประเมินผู้ขาย**: เลือกช่วงวันที่ ได้ต่อผู้ขาย มูลค่าซื้อ ส่งตรงเวลา % ส่งคืน % ระยะเวลาส่งเฉลี่ย คะแนน (60% ตรงเวลา + 40% ไม่ต้องคืน) และเกรด A/B/C
- **ค่าใช้จ่ายนำเข้า** (ค่าขนส่ง อากร) กระจายเข้าต้นทุนสินค้าของใบรับนั้น — คลิกใบรับในรายการเปิดหน้าดู (ป้าย ยังไม่มีค่าใช้จ่าย/รอปันส่วน/ปันส่วนแล้ว ปุ่มปันส่วนเข้าต้นทุน พิมพ์ / PDF แก้ไข) กดแก้ไขเพื่อใส่ค่าใช้จ่าย บิลละบรรทัด (ชนิด เลขที่เอกสารเช่นเลข AWB / B/L ผู้เรียกเก็บ จำนวนเงิน) แต่ละบรรทัดรอตั้งหนี้กับผู้เรียกเก็บของตัวเอง บรรทัดที่ปันส่วนแล้วแก้ไม่ได้

## ขาย

```
ใบเสนอราคา → ใบสั่งขาย → ใบส่งของ → ใบแจ้งหนี้/ใบกำกับภาษี → ใบวางบิล → รับชำระ
                                  ↘ ใบรับคืนสินค้า → ใบลดหนี้
```

- **ราคาขาย** ตามรายการราคาของลูกค้า แล้วรายการ `ALL` แล้วราคาสินค้า ระบบเติมราคาให้และดึงใหม่เมื่อเปลี่ยนจำนวน
- ใบสั่งขายไม่มีขั้นอนุมัติ ถ้าเกินวงเงินเครดิตจะบันทึกได้แต่ขึ้นคำเตือน
- ใบส่งของ: เปิดมาเติมจำนวนเท่าที่ค้างส่งและมีของ (ของพอส่งครบในใบเดียว) ระบบเลือกตำแหน่ง/ล็อตให้ (วันหมดอายุเก่าก่อน) ล็อตเดียวไม่พอก็แบ่งเป็นหลายแถว ใบแจ้งหนี้รวมกลับเป็นบรรทัดเดียวต่อบรรทัดใบสั่งขาย; กด **ยืนยันส่งของ** แล้วถามยืนยันอีกครั้ง
- ยืนยันส่งของแล้วเปิดใบแจ้งหนี้ที่เติมจากใบส่งของให้ตรวจ/แก้ (วันที่ ครบกำหนด เลขที่ PO ลูกค้า หมายเหตุ ราคา ส่วนลด) ก่อนบันทึก ใบแจ้งหนี้หนึ่งใบต่อใบส่งของ — ใบที่ยกเลิกทันที (เลขล่าสุด ยังไม่ส่ง e-Tax ไม่มีเอกสารอ้างถึง) ลบได้ เลขที่กลับไปใช้กับใบถัดไป
- ยกเลิกใบแจ้งหนี้ได้เฉพาะยังไม่ชำระและไม่อยู่ในใบวางบิลที่เปิดอยู่
- **รับคืนสินค้า** (ใบรับคืนสินค้า): เปิดใบส่งของแล้วกด **รับคืนสินค้า** ใส่เหตุผลและจำนวน ของกลับเข้าตำแหน่งและล็อตเดิมที่ต้นทุนตอนส่งออก ลงบัญชี Dr สินค้า / Cr ต้นทุนขาย แล้วรอใบลดหนี้ — หน้า **ใบแจ้งหนี้ / ใบลดหนี้** มีกล่อง **สินค้ารับคืนรอออกใบลดหนี้** กด **ออกใบลดหนี้** ได้ใบที่เติมลูกค้า ใบกำกับเดิม เหตุผล และรายการให้

## ผลิต

1. **สูตรการผลิต** ต่อสินค้า: เลือกสินค้าที่ผลิตครั้งเดียว แล้วแก้ในสองแท็บ **วัตถุดิบ** (ใช้ต่อ 1 หน่วย เผื่อเสีย % — วันเริ่ม/เลิกใช้และหมายเหตุเปิดจากปุ่ม ⋯ ของแถว) และ **ขั้นตอน** (ศูนย์งาน เวลาตั้งเครื่อง เวลาต่อชิ้น) กดบันทึกครั้งเดียวได้ทั้งสองแท็บ หัวตารางแสดงต้นทุนต่อหน่วย: วัตถุดิบ (จำนวน × (1 + เผื่อเสีย) × ต้นทุนปัจจุบัน) + ขั้นตอน (ชั่วโมงต่อชิ้น × อัตราค่าแรง+เครื่องจักร+โสหุ้ยของศูนย์งาน ไม่รวมเวลาตั้งเครื่อง)
2. **ใบสั่งผลิต**: สร้าง → เริ่มผลิต → **ใบเบิกวัตถุดิบ** (เลขชุด MI) → รับสินค้าผลิตเข้า (ของดี ของเสีย ผู้ตรวจ — ทุกครั้งออกใบ QC และลงชั่วโมงตามขั้นตอนการผลิตให้เอง) → ปิด — หน้าเดียวไม่มีแท็บ เรียงจากบนลงล่าง: วัตถุดิบ · ใบเบิก/ใบคืน · รับผลผลิต · แรงงาน · ต้นทุน กด **แก้ไข** ได้ระหว่างยังไม่เริ่มผลิต
   วัตถุดิบ: เปิดมาพร้อมยอดค้างเบิก ไล่ล็อตหมดอายุก่อน แตกหลายล็อตเอง บันทึกแล้วได้ใบเบิกหนึ่งใบ (พิมพ์ให้ผู้เบิก/คลัง/ผู้อนุมัติเซ็น) เบิกครบแล้วช่องเบิกซ่อน — **เบิกเพิ่ม** เกินสูตรต้องใส่เหตุผล; **คืนวัตถุดิบ** คืนเข้าล็อตที่เคยเบิก ไม่เกินที่เบิก ที่ต้นทุนตอนเบิก (ใบคืนวัตถุดิบ); ใบที่ผิดกดยกเลิกท้ายใบ ของกลับที่เดิม ใบเดิมยังอยู่พร้อมป้ายยกเลิก (จนกว่าจะปิดใบสั่งผลิต)
   แรงงาน: ไม่มีใครต้องจับเวลา — รับผลผลิตแล้วระบบลงชั่วโมงมาตรฐานเอง (เวลาเดินเครื่อง × (ของดี + ของเสีย) + เวลาตั้งเครื่องครั้งแรก) ที่อัตราศูนย์งาน ส่วนแรงงานแสดงชั่วโมง ค่าแรง ค่าโสหุ้ยต่อขั้นตอน (อ่านอย่างเดียว) มาตรฐานไม่ตรงแก้ที่ขั้นตอนการผลิต ค่าแรงจริงทั้งเดือนลงในสมุดรายวัน Dr ค่าแรงทางตรง ยอดคงเหลือของบัญชีนี้คือประสิทธิภาพแรงงานของเดือน
   ต้นทุน: รับเข้าคลังที่ต้นทุนมาตรฐานต่อหน่วย (สูตร × ต้นทุนตอนเบิก + ชั่วโมงตามขั้นตอน × อัตราศูนย์งาน) ตารางเทียบ มาตรฐาน / จริง / ผลต่าง (วัตถุดิบ ค่าแรง โสหุ้ย) ปิดใบแล้วงานระหว่างทำที่เหลือลงบัญชี **ผลต่างต้นทุนการผลิต** (50104, ตั้งค่าบัญชี)
3. **วางแผนวัตถุดิบ (MRP)** คำนวณจากใบสั่งขายค้างส่งและวัตถุดิบค้างเบิก แล้วสร้างใบขอซื้อหรือใบสั่งผลิตจากรายการที่เลือก — ทำแบบระบบ ERP ใหญ่: ผู้วางแผนกด **รัน MRP** (ระบบไล่สินค้าทีละระดับของสูตร หักสต็อก (เก็บสต็อกสำรอง) และกำหนดรับ ที่ขาดเป็นใบสั่งตามแผน ปัดตามขนาดสั่ง ควรสั่ง = กำหนดรับ − ระยะเวลาสั่ง) ผลอยู่จนรันครั้งถัดไป ได้ **ใบสั่งตามแผน** (ติ๊กแล้วสร้างใบขอซื้อ/ใบสั่งผลิต) **ข้อความแนะนำ** (ออกใบสั่ง / เลื่อนเข้า-เร่ง / เลื่อนออก / ยกเลิก ใบที่เปิดอยู่) และ **ตาราง MRP ตามสินค้า** ทุกสินค้าทั้งที่พอและไม่พอ คลิกแถวเห็นตาราง MRP แบบในตำราแบ่งตามสัปดาห์ (ความต้องการรวม กำหนดรับ ยอดคงคลังคาดการณ์ ความต้องการสุทธิ รับตามแผน ออกใบสั่งตามแผน) และที่มาของแต่ละตัวเลขตามวันที่
   **ฝ่ายผลิตรู้ได้ยังไงว่าต้องผลิตอะไร เท่าไร**: **ภาพรวมการผลิต** มีตาราง **ต้องผลิตตามใบสั่งขาย** — บรรทัดใบสั่งขายค้างส่งของสินค้าที่ผลิตเอง ที่ของในคลังไม่พอ พร้อมลูกค้า วันที่ต้องการ จำนวนที่ได้จากคลัง ใบสั่งผลิตที่ผลิตให้ และวันเสร็จ สถานะ **ต้องเปิดใบสั่งผลิต** (+ จำนวน) / **เสร็จไม่ทันกำหนด** / **ทันกำหนด** (จับคู่ชุดเดียวกับคิวรอส่งของ) แล้วไปเปิดใบสั่งผลิตจากคิว **แผนผลิตจาก MRP** ในหน้าใบสั่งผลิต — คิวทั้งสองในหน้านั้นมีคอลัมน์ **สำหรับ** บอกใบสั่งขาย/ลูกค้าที่ผลิตให้
4. **พนักงาน** (ผลิต → ตั้งค่า → พนักงานฝ่ายผลิต): ไม่มีระบบเงินเดือน — ผู้ใช้ที่เข้าระบบทำงานแต่ละขั้นคือพนักงาน เลือก **ผู้ใช้ที่เข้าระบบ** ให้พนักงานที่ล็อกอิน (ผู้ใช้หนึ่งคนผูกได้พนักงานเดียว) แล้วช่อง ผู้ขอซื้อ (ใบขอซื้อ) และผู้ตรวจ (QC) ใส่ชื่อของคนที่ล็อกอินให้ เลือกคนอื่นจากรายชื่อพนักงานหรือพิมพ์ชื่อเองได้

## บัญชี

เมนูบัญชีเรียงตามลำดับงาน — **เจ้าหนี้ (AP)**: **ตั้งหนี้ (AP)** (ทุกบรรทัดเลือกรหัสหัก ณ ที่จ่ายได้ ค่าเริ่มต้นจากผู้ขาย — จ่ายชำระเติมตารางหัก ณ ที่จ่ายจากบรรทัดให้เอง; ตั้งหนี้ที่ค้างจ่ายและยังไม่อยู่ในใบสำคัญจ่ายกด **แก้ไข** ได้ ลงบัญชีเฉพาะส่วนต่าง) จากใบรับ (คิวใบรับรอตั้งหนี้บนหน้า ติ๊กหลายใบของผู้ขายเดียวกันแล้วกดตั้งหนี้) หรือทำเอง เลือก **บัญชีเจ้าหนี้** ได้ (ค่าตั้งต้นจากผู้ขาย) หรือเป็น **ใบลดหนี้** จากผู้ขาย (อ้างถึงการตั้งหนี้เดิม) → **ใบสำคัญจ่าย (VO)** รวมตั้งหนี้หลายใบของผู้ขายเดียวกัน พิมพ์ไปเซ็น ลงบัญชี Dr บัญชีเจ้าหนี้ของแต่ละใบ / Cr เจ้าหนี้ตามใบสำคัญจ่าย → **จ่ายชำระ (PV)** เลือกใบสำคัญจ่ายหลายใบ (ปุ่มจ่ายชำระบนใบสำคัญจ่ายเปิดให้พร้อมยอด) ลงบัญชี Dr เจ้าหนี้ตามใบสำคัญจ่าย / Cr ธนาคาร / Cr ภาษีหัก ณ ที่จ่าย → **รายงานภาษีซื้อ** → หนังสือรับรองหัก ณ ที่จ่าย; **ลูกหนี้ (AR)**: ใบแจ้งหนี้ขาย (จากใบส่งของ) และ **ใบแจ้งหนี้ / ใบลดหนี้ / ใบเพิ่มหนี้** ที่สร้างเอง (ไม่ต้องมีใบส่งของ ใบลดหนี้และใบเพิ่มหนี้ต้องอ้างใบแจ้งหนี้เดิมของลูกค้าเดียวกัน — ใบลดหนี้ได้เลขชุด CN ลดลูกหนี้ ภาษีขาย และรายได้, ใบเพิ่มหนี้ได้เลขชุด DN เพิ่มเหมือนใบแจ้งหนี้ — ทั้งสองต้องเลือก **เหตุผล** ตามรหัสของกรมสรรพากร เช่น CDNG02 สินค้าชำรุดเสียหาย, DBNG01 มีการเพิ่มราคาค่าสินค้า ถ้าเลือก "เหตุอื่น" ต้องเขียนเหตุผลในหมายเหตุ เหตุผลพิมพ์ในเอกสารและใช้ใน XML e-Tax) → สมุดรายวันขาย (รายการบัญชีที่ใบแจ้งหนี้ลงให้) → **รายงานภาษีขาย** → ลูกหนี้คงค้าง → รับชำระเงิน (ใบลดหนี้ที่ค้างอยู่หักกับใบแจ้งหนี้ในใบรับเงินเดียวกันได้ ยอดรับสุทธิต้องไม่ติดลบ); แล้วสินทรัพย์ถาวร (FA) และบัญชีแยกประเภท (GL) รายงานภาษีซื้อ/ขายเลือกเดือนภาษี แสดงเลขที่ใบกำกับ ชื่อ เลขผู้เสียภาษี สาขา มูลค่า และภาษี (เป็นบาท) พิมพ์เป็น PDF แนวนอนสำหรับยื่น ภ.พ.30

**เงินสดย่อย** (บัญชี → เงินสดและธนาคาร): ทุกคนที่มีสิทธิ์หน้านี้มีกล่องเงินสดย่อยของตัวเอง และทำรายการได้เฉพาะกล่องตัวเอง (ไม่มีวงเงิน — เงินที่รับมาเป็นภาระของผู้ถือ) รายการ: **เบิกจากธนาคาร** (Dr เงินสดย่อย / Cr ธนาคาร), **รับเงินจากผู้ถืออื่น** (ผู้รับบันทึก ได้ 2 รายการคนละเลขที่ ส่งเงินให้ − / รับเงินจาก + ไม่ลงบัญชี), **จ่ายค่าใช้จ่าย** (บรรทัดบัญชี ศูนย์ต้นทุน จำนวนเงินก่อน VAT; มีใบกำกับภาษีเต็มรูปแยกภาษีซื้อเข้ารายงานภาษีซื้อ; หัก ณ ที่จ่ายตามรหัสในบรรทัด ต้องเลือกผู้ขาย ได้ 50 ทวิ เลขชุดเดียวกับจ่ายชำระ) **รับเงิน (รายรับ)** เช่น ขายเศษของ (Dr เงินสดย่อย / Cr รายได้อื่น) และ **คืนเข้าธนาคาร** — รับเงินจากผู้ถืออื่นแก้/ยกเลิกไม่ได้ (ผิดให้ผู้ส่งรับคืน) ทุกรายจ่ายต้องมีเลขที่ใบเสร็จ ใบกำกับ หรือไฟล์แนบก่อนนับเงิน ตารางของหน้าแสดงเงินสดย่อยทุกคนในเดือน (ยกมา รายการ คงเหลือรายคนและรวม) ส่งออก Excel ได้ — จ่ายชำระเจ้าหนี้ รับชำระเงิน และรับเงินมัดจำ เลือกบัญชี **CASH เงินสดย่อย (ของผู้ทำรายการ)** ได้ เงินออก/เข้ากล่องของผู้ทำเอกสาร (บัญชีนี้ไม่อยู่ในกระทบยอดธนาคาร) — ทุกรายการมีเลขที่ PC เรียงตามเดือนของวันที่รายการ แนบรูปหรือ PDF ได้ พิมพ์ใบสำคัญได้ แก้ไข/ยกเลิกได้เฉพาะรายการที่ตัวเองลงไว้ในเดือนที่ยังไม่นับ (เลขที่เดิม) — นับแล้วลืมลงรายการ: ยกเลิกการนับ ลงหรือแก้รายการ แล้วนับใหม่ ทุกสิ้นเดือนผู้ถือ **นับเงิน** (จำนวนธนบัตร/เหรียญ) ส่วนต่างลงบัญชีเงินขาดเกินบัญชี แล้วเดือนนั้นถูกล็อก — ยังไม่นับ ทำรายการเดือนถัดไปไม่ได้ และปิดงวดบัญชีไม่ได้ ปุ่ม **ทะเบียนเงินสดย่อย** พิมพ์รายการของเดือนพร้อมใบนับเงิน

**บัญชีธนาคาร** (บัญชี → เงินสดและธนาคาร): ตารางแสดงยอดคงเหลือวันนี้ (จากบัญชีแยกประเภท) วันที่กระทบยอดล่าสุด และจำนวนรายการรอกระทบ คลิกแถวเปิด **สมุดบัญชีเงินฝาก** — เลือกเดือนได้ ยอดยกมา เงินเข้า เงินออก คงเหลือสะสม วันที่กระทบยอดของแต่ละรายการ และคงเหลือสิ้นเดือน คลิกรายการเปิดสมุดรายวันของรายการนั้น ส่งออก Excel และพิมพ์ได้ (แถวเงินสดย่อยไปหน้าเงินสดย่อย) ไอคอนดินสอแก้ค่าตั้ง

**กระทบยอดธนาคาร** (บัญชี → เงินสดและธนาคาร): เลือกบัญชีธนาคารและวันที่ statement แล้วติ๊กรายการในบัญชีที่ปรากฏใน statement (คลิกทั้งแถวได้) — ยอดกระทบครั้งก่อน + รายการที่ติ๊ก = **ยอดหลังกระทบ** ผู้ใช้เทียบกับยอดคงเหลือใน statement จริงเอง ตรงแล้วบันทึก (เก็บเป็นยอดตาม statement ของครั้งนั้น); รายการที่ไม่ได้ติ๊กจะค้างไว้ให้ครั้งถัดไป ใต้ตารางมีประวัติการกระทบยอด พิมพ์ **งบกระทบยอดเงินฝากธนาคาร** (ยอดตาม statement + เงินฝากระหว่างทาง − รายการจ่ายที่ธนาคารยังไม่ลง = ยอดตามบัญชี) และยกเลิกได้เฉพาะครั้งล่าสุด ยอดเป็นเงินบาทตามบัญชี GL ที่ผูกกับบัญชีธนาคาร

**e-Tax Invoice by Email** (สำหรับผู้ประกอบการรายได้ไม่เกิน 30 ล้านบาทต่อปี ที่ลงทะเบียนอีเมลกับสรรพากรแล้ว): ตั้งค่าที่ บัญชี → ตั้งค่า → **ตั้งค่า e-Tax / อีเมล** — อีเมลผู้ส่ง (ต้องเป็นอีเมลที่ลงทะเบียน) SMTP server พอร์ต การเข้ารหัส ชื่อผู้ใช้ รหัสผ่าน (เก็บใน config.php ไม่อยู่ในฐานข้อมูล) ปีในหัวข้อ (พ.ศ./ค.ศ.) และสำเนาถึง `csemail@etax.teda.th` กด **ส่งทดสอบ** ก่อนเปิดใช้ แล้วหน้าใบแจ้งหนี้/ใบลดหนี้จะมีปุ่ม **ส่ง e-Tax**: ใส่อีเมลผู้ซื้อ (ค่าเริ่มต้นจากลูกค้า) ระบบสร้าง PDF ใบกำกับภาษีเป็น **PDF/A-3B** ตามที่ สพธอ. กำหนด (ไม่เกิน 3 MB) ส่ง 1 ฉบับต่ออีเมล ถึงผู้ซื้อ 1 คน สำเนาถึงระบบ สพธอ. ซึ่งประทับเวลาแล้วส่งต่อให้ผู้ซื้อ หัวข้ออีเมลตามรูปแบบ `[วันที่][INV][เลขที่]`, ใบลดหนี้ `[วันที่][CDN][เลขที่][เลขใบกำกับที่อ้างถึง]`, ใบเพิ่มหนี้ `[วันที่][DBN][เลขที่][เลขใบกำกับที่อ้างถึง]`, ใบกำกับที่ยกเลิก `[วันที่][CIV][เลขที่]` — ทุกครั้งที่ส่ง (สำเร็จหรือไม่) อยู่ในหน้า **e-Tax Invoice (อีเมล)** ใต้ลูกหนี้ (เมนูนี้แสดงเมื่อเปิดใช้แบบอีเมล มีใบรับรองสำหรับ XML หรือเคยส่งแล้ว)

**e-Tax Invoice แบบ XML** (ผู้ที่ได้รับอนุมัติจากสรรพากรให้จัดทำ e-Tax Invoice & e-Receipt — ใช้ได้ทางเดียว ไม่ใช้คู่กับแบบอีเมล): อัปโหลดใบรับรอง (.p12/.pfx จาก CA ภายใต้ Thailand NRCA เช่น Thai Digital ID, INET, NT, ThaiCA) และรหัสผ่านที่ **ตั้งค่า e-Tax / อีเมล** แล้วหน้าใบแจ้งหนี้/ใบลดหนี้จะมีปุ่ม **XML e-Tax** ดาวน์โหลด XML ตามมาตรฐาน ขมธอ.3-2560 ที่ลงลายมือชื่อแบบ XAdES-BES (RSA-SHA512) — ใบกำกับภาษี (388), ใบลดหนี้ (81) และใบเพิ่มหนี้ (80) ระบุมูลค่าเดิม มูลค่าที่ถูกต้อง ผลต่าง รหัสเหตุผลที่เลือก และคำอธิบายจากหมายเหตุ (ไม่มีหมายเหตุใช้คำของรหัส); หน้าใบรับชำระเงินมีปุ่ม **XML e-Tax** เป็นใบรับ (T01) แต่ละบรรทัดคือใบแจ้งหนี้ที่รับชำระ (ใบลดหนี้ที่นำมาหักเป็นส่วนลด) ไฟล์ที่ลงนามแล้วถูกเก็บไว้และให้ไฟล์เดิมทุกครั้ง หน้า **e-Tax Invoice (อีเมล)** มีปุ่ม **XML ประจำเดือน** ได้ zip ของทุกเอกสารในเดือน (ใบกำกับภาษี ใบลดหนี้ ใบเพิ่มหนี้ ใบรับ) (ที่สร้างไม่ได้อยู่ใน errors.txt) สำหรับ "Upload XML" ที่ etax.rd.go.th ภายในวันที่ 15 ของเดือนถัดไป (ไฟล์ละไม่เกิน 3 MB) — ต้องกรอกข้อมูลบริษัทให้ครบ: เลขผู้เสียภาษี 13 หลัก สาขา 5 หลัก ที่อยู่ขึ้นต้นด้วยบ้านเลขที่ ตำบล อำเภอ จังหวัด รหัสไปรษณีย์ (ระบบแปลงเป็นรหัสตามทะเบียน) และลูกค้าต้องมีที่อยู่กับรหัสไปรษณีย์; เอกสารที่ยกเลิกไม่มี XML ให้ออกใบลดหนี้แทน

**รายงาน ภ.ง.ด.3 / 53** (บัญชี → เจ้าหนี้): เลือกแบบ (ภ.ง.ด.53 นิติบุคคล / ภ.ง.ด.3 บุคคลธรรมดา) และเดือน แสดงหนังสือรับรองหัก ณ ที่จ่ายที่ออกจากการจ่ายชำระในเดือนนั้น (ยกเว้นที่ยกเลิก) พร้อมเลขผู้เสียภาษี สาขา ชื่อที่อยู่ วันที่จ่าย ประเภทเงินได้ อัตรา จำนวนเงินที่จ่าย และภาษีที่หัก พิมพ์เป็นแบบฟอร์มของกรมสรรพากร: หน้าแบบยื่นรายการ (A4 แนวตั้ง: เลขผู้เสียภาษี สาขา ที่อยู่ ติ๊กเดือน มาตราที่นำส่ง จำนวนรายและแผ่นของใบแนบ สรุปยอด) ตามด้วยใบแนบ (A4 แนวนอน 6 รายต่อแผ่น รายละ 3 บรรทัด มีอัตราภาษีและเงื่อนไข) — ลำดับที่เป็นรายผู้มีเงินได้และตรงกับลำดับที่ในหนังสือรับรอง 50 ทวิ สำหรับยื่นภายในวันที่ 7 ของเดือนถัดไป

| ผลิต | เบิก Dr งานระหว่างทำ / Cr วัตถุดิบ; แรงงาน Dr งานระหว่างทำ / Cr ค่าแรงทางตรง, Cr ค่าโสหุ้ยการผลิตจัดสรร; รับเข้า Dr สินค้า / Cr งานระหว่างทำ |

- **สมุดรายวัน** ดูรายการทั้งหมดแยกตามประเภท บันทึกรายการเองได้ (ต้องสมดุล ลงบัญชีคุมไม่ได้) แก้ไขโดย **กลับรายการ**
- **ลูกหนี้** แสดงอายุหนี้ ยังไม่ครบกำหนด / 1–30 / 31–60 / 61–90 / เกิน 90 วัน
- **จ่ายชำระเจ้าหนี้** เลือกแบบ ภ.ง.ด.3 / ภ.ง.ด.53 และรหัสภาษีหัก ณ ที่จ่ายในตารางหัก ณ ที่จ่ายใต้รายการ (ยอดก่อนหักของอัตราแรกตั้งจากยอดก่อน VAT ให้) ใบเดียวหักได้หลายอัตรา เช่น ค่าบริการ 3% กับค่าขนส่ง 1% — กด **เพิ่มอัตรา** แล้วแบ่งยอดก่อนหัก (รวมกันไม่เกินยอดจ่าย ใช้รหัสซ้ำไม่ได้) ทุกอัตราอยู่ใน 50 ทวิ ใบเดียว อัตราแรกเป็นบรรทัดใต้แถวประเภทเงินได้ อัตราถัดไปที่อยู่แถวเดียวกันลงแถว "6. อื่น ๆ (ระบุ)" พร้อมชื่อประเภท ทุกบรรทัดแสดง "อัตราร้อยละ" จำนวนเงินที่จ่าย และภาษีที่หัก และเป็นบรรทัดแยกในรายงาน ภ.ง.ด. — พิมพ์บนแบบฟอร์มของกรมสรรพากร 2 ฉบับ (ฉบับที่ 1 ผู้ถูกหักภาษีใช้แนบแบบแสดงรายการภาษี, ฉบับที่ 2 ผู้ถูกหักภาษีเก็บไว้เป็นหลักฐาน) เลขผู้เสียภาษีในช่อง 13 หลัก ติ๊กแบบ ภ.ง.ด. ลำดับที่ตรงกับรายงาน ภ.ง.ด. ของเดือนนั้น ยอดลงแถวประเภทเงินได้ตาม **รหัสภาษีหัก ณ ที่จ่าย** (ช่อง "ประเภทเงินได้ในแบบ 50 ทวิ" ค่าเริ่มต้นแถว 5: ค่าจ้างทำของ ค่าโฆษณา ค่าเช่า ค่าขนส่ง ค่าบริการ)
- **รับเงินมัดจำ** (ปุ่มบนใบสั่งขาย): ใส่ยอดที่รับ (รวม VAT) ระบบแยกมูลค่ากับภาษี ได้ **ใบรับเงินมัดจำ / ใบกำกับภาษี** ภาษีถึงกำหนดตอนรับเงิน — ใบกำกับภาษีตอนส่งของของใบสั่งขายนั้นหักมัดจำออกจากมูลค่าแล้วคิดภาษีเฉพาะส่วนที่เหลือ ลงบัญชี Dr ธนาคาร / Cr เงินมัดจำรับ, Cr ภาษีขาย แล้วตอนหัก Dr เงินมัดจำรับ
- **งานบริการ** (ใบแจ้งหนี้ที่ทำเอง เลือก **ภาษีขายถึงกำหนด: เมื่อรับชำระ**): ภาษีขายถึงกำหนดเมื่อได้รับเงิน (ม.78/1) ใบแจ้งหนี้พิมพ์เป็น "ใบแจ้งหนี้" ภาษีพักที่ ภาษีขายยังไม่ถึงกำหนด แล้วทุกครั้งที่รับชำระ ส่วนที่ถึงกำหนดย้ายเป็นภาษีขาย ใบรับชำระพิมพ์เป็น **ใบเสร็จรับเงิน / ใบกำกับภาษี** และเข้ารายงานภาษีขายตามวันที่รับเงิน
- **งบทดลอง** เลือกช่วงวันที่ คลิกบัญชีเพื่อดูบัญชีแยกประเภท คลิกรายการเพื่อเปิด
- **ภ.พ.30** (บัญชีแยกประเภท): เลือกเดือนภาษี ระบบรวมภาษีขาย − ภาษีซื้อ − ภาษีชำระเกินยกมา พิมพ์ใบสรุปสำหรับกรอกแบบ กด **ยื่นและลงบัญชี** ปิดภาษีขายและภาษีซื้อเข้า ภาษีมูลค่าเพิ่มค้างจ่าย (หรือชำระเกินยกไป) — จ่ายภาษีให้สรรพากรบันทึกในสมุดรายวัน ยกเลิกได้เฉพาะเดือนล่าสุด
- **งบการเงิน**: งบแสดงฐานะการเงิน ณ วันที่ และงบกำไรขาดทุนของช่วงวันที่ จัดหมวดตามรหัสบัญชี (สินทรัพย์หมุนเวียน 10–13, หนี้สินหมุนเวียน 20–22, ต้นทุนขาย 501 ฯลฯ) กำไรปีนี้อยู่ในส่วนของผู้ถือหุ้น พิมพ์ / PDF ได้
- **ปิดงวด** (ปุ่มในหน้างบทดลอง) เมื่อสิ้นเดือนแล้วและลงค่าเสื่อมของเดือนนั้นครบ — หลังปิดลงรายการย้อนหลังในงวดนั้นไม่ได้ ปีบัญชีเท่ากับปีปฏิทิน

## ถาม AI

เมนู **ถาม AI** ถามข้อมูลเป็นภาษาคนได้ เช่น “ใบสั่งซื้อที่ยังไม่ได้รับของ” “ลูกค้าที่ค้างชำระเกิน 30 วัน” “สินค้าไหนเหลือน้อย”

- AI อ่านข้อมูลผ่าน API เดียวกับหน้าจอ และเห็นเฉพาะข้อมูลที่ผู้ถามมีสิทธิ์ดู
- AI อ่านได้อย่างเดียว ไม่สร้างหรือแก้ไขข้อมูล
- ใต้คำตอบบอกว่าดูข้อมูลจากที่ใด ตรวจสอบตัวเลขสำคัญกับหน้าจอก่อนนำไปใช้
- ผู้ดูแลตั้งผู้ให้บริการ (Claude / Gemini) API key และราคา ใน **ตั้งค่าระบบ › ตั้งค่า AI** และดูค่าใช้จ่ายรายคนได้ที่หน้าเดียวกัน

## เอกสารลงนาม (e-Document Sign)

เมนู **เอกสารลงนาม › ซองเอกสาร** ส่งเอกสารจากข้างนอก (PDF หรือรูป) ให้คนในองค์กรเซ็นตามลำดับ เช่น ผู้ช่วยผู้จัดการ → ผู้จัดการ → เจ้าของ

1. **สร้างซองใหม่** (ต้องมีสิทธิ์เพิ่มของหน้า ซองเอกสาร) อัปโหลด **เอกสารหลัก** (ไฟล์ที่มีช่องเซ็น) และ **แนบท้าย** — ไฟล์ Word ให้บันทึกเป็น PDF ก่อน PDF ที่ตั้งรหัสผ่านอัปโหลดไม่ได้ ระบบทำไฟล์ให้สะอาด (ตัด JavaScript ลิงก์ ฟอร์ม) ก่อนเก็บ
2. เพิ่ม **ผู้ลงนาม** เลือกผู้ใช้ ตำแหน่ง และบทบาท ลงนาม / อนุมัติ / รับทราบ ลูกศรเลื่อนขั้น — คนในขั้นเดียวกันเซ็นพร้อมกัน ขั้นถัดไปเริ่มเมื่อขั้นก่อนเซ็นครบ
3. เลือกผู้ลงนาม แล้วเลือกชนิดช่อง (ลายเซ็น ชื่อย่อ ชื่อ ตำแหน่ง วันที่ลงนาม เวลารับ·เปิด·เซ็น ตราบริษัท ข้อความ ช่องติ๊ก) คลิกวางบนหน้าเอกสาร ผู้ส่งใส่ **กล่องข้อความ** และ **ตราคำ** (อนุมัติ ด่วน สำเนาถูกต้อง ...) เองได้ — ช่องคัดลอกไปทุกหน้า / ทุกหน้ายกเว้นหน้าแรก / หน้าที่เลือก แบบเชื่อมกันได้ และลบจากหลายหน้าในครั้งเดียว
4. ดู **ตรวจก่อนส่ง** แล้วกด **ส่ง** — ส่งแล้วแก้ไม่ได้
5. ผู้ลงนามเห็นที่ **รอฉันเซ็น** (และปุ่มซองจดหมายแถบบน) เปิดแล้วกรอกช่องของตัวเอง เซ็นด้วยลายเซ็นที่ตั้งไว้หรือวาดใหม่ หรือ **ไม่อนุมัติ** พร้อมเหตุผล
6. เซ็นครบแล้ว ทุกคนในซองได้ **ฉบับสุดท้าย** ฉบับเดียวกัน (อีเมลแนบไฟล์ถ้าตั้งค่าอีเมลไว้ และที่แท็บ **เอกสารของฉัน**)

ฉบับสุดท้ายมีท้ายกระดาษทุกหน้า (เลขซอง หน้า x / รวม ไฟล์ไหนหน้าไหน QR) และหน้า **หลักฐานการลงนาม**: จำนวนหน้าของทุกไฟล์ ลายนิ้วมือ SHA-256 ทั้งไฟล์และรายหน้า ผู้ลงนามพร้อมเวลารับ เปิด เซ็น และประวัติทั้งหมดที่เก็บเป็นโซ่ hash — หน้า **ตรวจเอกสาร** บอกว่าไฟล์ที่ได้รับตรงกับฉบับที่เซ็นหรือไม่ ถ้าไม่ตรงบอกว่าหน้าไหนต่าง

ยังส่งให้คนนอกองค์กรไม่ได้ (รอบริการ phai.monrak.net) เวลาทั้งหมดเป็นนาฬิกาของเครื่องแม่ข่าย

## ผู้ใช้และความปลอดภัย

- ผู้ใช้หนึ่งคนมีหนึ่งบทบาท ปิดใช้งานผู้ใช้ได้แต่ไม่ลบ ทุกการแก้ไขข้อมูลถูกบันทึกในประวัติ (audit log)
- ใส่รหัสผ่านผิด 5 ครั้งใน 15 นาที บัญชีจะถูกล็อกชั่วคราว
- เปลี่ยนรหัสผ่านของตัวเองได้จากเมนูชื่อผู้ใช้มุมขวาบน


ตารางรายการมีปุ่ม **เลือกคอลัมน์** สำหรับเลือกแสดงหรือซ่อนฟิลด์ โดยบันทึกค่าแยกแต่ละตารางลงฐานข้อมูล ใช้ร่วมกันทุกคนเมื่อเปิดหน้าหรือรีเฟรช กด **คืนค่าเริ่มต้น** เพื่อกลับค่าเดิม ประวัติความเคลื่อนไหวคือ transaction สต็อก เลือกแสดงเลข transaction เวลา บรรทัดเอกสาร ราคา ต้นทุน มูลค่าเคลื่อนไหว (จำนวน × ต้นทุน มีเครื่องหมายรับ/เบิก) และหมายเหตุได้

ช่องค้นหาของตารางรายการค้นหาทุกฟิลด์ข้อมูลที่เปิดเผยได้ รวมฟิลด์เพิ่มเติม โดยค้นหาก่อนแบ่งหน้า ปุ่มเลือกคอลัมน์เป็นไอคอนด้านขวาของแถวหัวตาราง

ไอคอน **ส่งออก Excel** (ข้างปุ่มเลือกคอลัมน์) ให้ไฟล์ .xlsx ของทุกแถวตามคำค้นและตัวกรองปัจจุบัน (ไม่ใช่แค่หน้าที่เห็น) เฉพาะคอลัมน์ที่แสดง เรียงตามลำดับบนหน้าจอ ตัวเลขและวันที่เป็นค่าที่ Excel คำนวณได้ หัวตารางตรึงไว้และเปิดตัวกรองไว้ให้

หน้าข้อมูลหลักมีไอคอน **นำเข้าจาก Excel** สำหรับผู้มีสิทธิ์เพิ่มหรือแก้ไข: กด **ไฟล์ตัวอย่าง** เพื่อได้ไฟล์ที่หัวคอลัมน์ตรงกับฟอร์ม (หัวสีแดง = ช่องบังคับ แผ่นที่สอง = ค่าที่เลือกได้) หน้าข้อมูลหลักส่งออกทุกช่องของฟอร์มเหมือนไฟล์ตัวอย่าง (ไม่ขึ้นกับคอลัมน์ที่เลือกแสดง) จึงแก้ไฟล์ที่ส่งออกแล้วนำเข้ากลับได้ทันที แถวที่มีรหัสอยู่แล้วจะถูกแก้ไข (คอลัมน์ที่ไม่มีในไฟล์ไม่ถูกแตะ ช่องว่างคือล้างค่า) แถวใหม่จะถูกเพิ่ม ถ้ามีแถวใดผิด ระบบไม่บันทึกเลยสักแถวและแสดงรายการ "แถว N · ช่อง: ข้อความ" ให้แก้แล้วนำเข้าใหม่ ครั้งละไม่เกิน 5,000 แถว

### สายผลิตภัณฑ์ (Product Line) และกลุ่มเมนู

ไปที่ **ข้อมูลหลัก → สายผลิตภัณฑ์** เลือกสายเดิมหรือกดเพิ่ม กรอกรหัส/ชื่อ และกำหนด **ประเภทสต็อก** เป็น FG หรือ RM พร้อมภาษี สถานะ และบัญชีในแท็บ **บัญชี** (สินค้าคงคลัง รายได้ขาย ต้นทุนขาย ซื้อ และงานระหว่างทำ) ตามผังบัญชีของบริษัท รหัสสายใช้ชื่ออื่นได้ เช่น FG-FURNITURE หรือ RM-STEEL แล้วเลือกสายนี้ในช่อง **สายผลิตภัณฑ์** ของแต่ละสินค้า ระบบจะกรองในหน้า **สินค้าและวัตถุดิบ** และยอดคงเหลือตามประเภทของสายโดยไม่มีช่อง FG/RM ซ้ำในฟอร์มสินค้า ที่มาซื้อมา/ผลิตเองแยกจากประเภทนี้

ติดตั้งใหม่มีสายพร้อมบัญชีให้แล้ว: **FG** (สินค้า 12101 ขาย 40101 ต้นทุนขาย 50101 งานระหว่างทำ 12102), **RM** (วัตถุดิบ 12103) และสายประเภท **FA** สินทรัพย์ถาวร (BD อาคาร, MC เครื่องจักรและอุปกรณ์, OF อุปกรณ์สำนักงาน, VH ยานพาหนะ — หมวดสินทรัพย์ใช้รหัสเดียวกัน) ซึ่งผูกกับหมวดสินทรัพย์ที่ติดตั้งมาพร้อมบัญชีสินทรัพย์ ค่าเสื่อมสะสม ค่าเสื่อม (50901) และกำไร/ขาดทุนจำหน่าย (40204) ซื้อเครื่องจักรเป็นรายการในสาย FA ผ่านใบสั่งซื้อ รับของแล้วยอดเข้าบัญชีสินทรัพย์ของหมวด จากนั้นขึ้นทะเบียนสินทรัพย์แบบ **ทุนลงบัญชีไว้แล้ว** อ้างเลขใบรับ ทะเบียนสินทรัพย์มีช่อง **ใช้ผลิตสายผลิตภัณฑ์** และหน้า **ผลิต › เครื่องจักร** มีช่อง **รหัสสินทรัพย์ถาวร** ให้ผูกเครื่องกับสินทรัพย์ รายการเดิมที่ยังใช้ GEN จะนับเป็นประเภท FG ในหน้า **สินค้าและวัตถุดิบ** ให้แก้สายทีละรายการ ถ้า GEN มีทั้งสินค้าและวัตถุดิบ อย่าเปลี่ยนประเภท GEN รวมทั้งหมด เพราะการเปลี่ยนประเภทสายมีผลกับทุกรายการที่ใช้สายนั้น แต่ไม่แก้รายการบัญชีในอดีต การตั้งบัญชีแยก FG/RM ให้เลือกตามผังบัญชีของบริษัทเอง รายการใหม่ต้องใช้สายที่เปิดใช้งานและมีประเภท FG/RM แล้ว

คลิกกลุ่มเมนูใน sidebar เพื่อเปิด กลุ่มอื่นจะปิดอัตโนมัติ คลิกกลุ่มเดิมซ้ำเพื่อปิด ใช้งานเหมือนกันบนคอมพิวเตอร์และมือถือ

### สินทรัพย์ถาวร (Fixed Assets)

1. ไปที่ **บัญชี → หมวดสินทรัพย์ถาวร** เพิ่มหมวด ระบุวิธีเส้นตรง/ยอดลดลง/ไม่คิดค่าเสื่อม อายุใช้งาน อัตราต่อปี และบัญชีสินทรัพย์ ค่าเสื่อมสะสม ค่าเสื่อม และกำไร/ขาดทุนจำหน่าย ให้ต่างกันและไม่เป็นบัญชีคุม
2. ไปที่ **บัญชี → ทะเบียนสินทรัพย์ → เพิ่ม** กรอกทะเบียน ราคาทุน มูลค่าซาก วันที่ได้มา/เริ่มใช้ สาขา ผู้รับผิดชอบ (เลือกพนักงานหรือพิมพ์ชื่อ) และ **เอกสารซื้ออ้างอิง** — ซื้อผ่านใบสั่งซื้อด้วยสินค้าสายสินทรัพย์ (FA) เลือกจากใบรับสินค้า (เลขใบกำกับของผู้ขาย) ได้ ระบบเติมผู้ขาย วันที่ได้มา ทุน และหมวดให้ (ใบรับลงบัญชีสินทรัพย์ไว้แล้ว ขึ้นทะเบียนแบบทุนลงบัญชีไว้แล้ว) บันทึกร่าง แนบรูป/PDF ที่เกี่ยวข้อง (ใบกำกับ ใบรับประกัน รูป) ในหัวข้อ **เอกสารแนบ** ตรวจสอบแล้วเปิดหัวข้อ **ขึ้นทะเบียน / รับสินทรัพย์**
3. ถ้าทุนลงบัญชีผ่านเจ้าหนี้หรือสมุดรายวันแล้ว ให้เลือก **ทุนลงบัญชีไว้แล้ว** กรณีนำทะเบียนเดิมเข้าระบบ ระบุค่าเสื่อมสะสมยกมาและเดือนที่ยอดครอบคลุมถึง กรณีลงทุนใหม่เลือกบัญชีเครดิต ระบบลงทุนโดยไม่สร้างเจ้าหนี้หรือภาษีซื้อเพิ่ม
4. **ค่าเสื่อมรายเดือน** แสดงผลตรวจสอบก่อนลงบัญชี เลือกสินทรัพย์แล้วลงบัญชีทั้งชุด หรือทำทีละสินทรัพย์ ต้องต่อเนื่องและเป็นเดือนที่สิ้นสุดแล้วในงวดเปิด รายการซ้ำถูกปฏิเสธ
5. เส้นตรง = (ทุน−ซาก)/อายุเดือน ยอดลดลง = มูลค่าคงเหลือ×อัตราต่อปี/12 คิดเต็มเดือนเริ่มใช้ ไม่เฉลี่ยรายวัน เดือนสุดท้ายปรับส่วนที่เหลือให้ตรงมูลค่าซาก ตารางประมาณการยังไม่ใช่รายการลงบัญชี
6. เปิด **โอนสถานที่ / ผู้รับผิดชอบ** เพื่อเปลี่ยนสาขา ศูนย์ต้นทุน สถานที่ ผู้ดูแล โดยไม่เปลี่ยนบัญชี เมื่อขายหรือตัดทิ้ง ใช้ **ขาย / ตัดจำหน่าย** ลงค่าเสื่อมถึงเดือนก่อนจำหน่ายก่อน ไม่มีค่าเสื่อมเดือนจำหน่าย ระบุราคาขายสุทธิและบัญชีรับเงิน/พักจำหน่าย ภาษีขายและการรับเงินบันทึกในเอกสารบัญชีแยก ใช้บัญชีพักเพื่อไม่บันทึกยอดซ้ำ
7. แก้รายการลงบัญชีด้วย **กลับรายการล่าสุด** พร้อมวันที่ในงวดเปิดและเหตุผล ประวัติเดิมคงอยู่ ปุ่มพิมพ์/PDF มีในทะเบียน รายงานทะเบียนรวม และรายงานค่าเสื่อมรายเดือน

ผู้ใช้ต้องมีสิทธิ์แก้ไขของสินทรัพย์ถาวรจึงทำร่าง โอน รับสินทรัพย์ ลงค่าเสื่อม จำหน่าย และกลับรายการได้ สิทธิ์พิมพ์แยกจากสิทธิ์ดู ระบบนี้ยังไม่แยกทะเบียนภาษี ไม่รองรับตีราคาใหม่ และไม่ได้เชื่อมใบซื้ออัตโนมัติ

## เมนูผู้ใช้ และธีม

**ภาษา**: ธงข้างปุ่ม ช่วยเหลือ (ขวาบน) สลับไทย / อังกฤษ — หน้าจอภาษาไทยมีธงสหรัฐ (EN) หน้าจอภาษาอังกฤษมีธงไทย (TH) กดแล้วโหลดหน้าใหม่เป็นภาษานั้นและจำไว้กับผู้ใช้ หน้าเข้าระบบก็มีธงเดียวกัน เอกสารที่พิมพ์ (ใบกำกับภาษี 50 ทวิ ภ.ง.ด. ภ.พ.30 รายงาน) เป็นภาษาไทยเสมอตามกฎหมายภาษี และข้อมูลที่กรอก (ชื่อลูกค้า ชื่อสินค้า) แสดงตามที่กรอก — หน้าช่วยเหลือและเรียนรู้ ERP ก็เป็นภาษาอังกฤษด้วย

เมนูชื่อผู้ใช้ขวาบนเปิดเป็นการ์ดรูปและชื่อ มี **โปรไฟล์ของฉัน** (แก้ชื่อ อีเมล โทรศัพท์ มือถือ และรูปโปรไฟล์ PNG/JPG/WebP ขนาดเท่าไรก็ได้ ระบบย่อให้เอง — ไม่มีรูปแสดงอักษรย่อของชื่อ) และ **เปลี่ยนรหัสผ่าน** ส่วน **ธีม** คือปุ่มจานสีบนแถบบน ข้างธงภาษา เป็นวงสีให้เลือก 6 แบบ: **ไผ่** (เขียว ค่าเริ่มต้น) **หมอก** (ขาว-เทา) **คราม** (น้ำเงิน) **อัญชัน** (ม่วง) **ดินเผา** (ส้มอิฐ) และ **ไผ่ยามค่ำ** (มืด) — กดแล้วเปลี่ยนทันที (เมนูยังเปิดอยู่ ลองได้หลายสี) และจำไว้กับผู้ใช้ (เข้าจากเครื่องไหนก็ได้ธีมเดิม) เอกสารที่พิมพ์และ PDF เป็นพื้นขาวเสมอ
