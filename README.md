# Phai ERP

ระบบ ERP ภาษาไทยแบบโอเพนซอร์ส สำหรับธุรกิจขนาดเล็กถึงกลาง ครบตั้งแต่จัดซื้อ คลังสินค้า ผลิต ขาย ไปจนถึงบัญชีและภาษีไทย มีระบบเซ็นเอกสารอิเล็กทรอนิกส์และผู้ช่วย AI ในตัว เขียนด้วย PHP ล้วน ไม่ต้อง build และใช้งานได้โดยไม่ต้องต่ออินเทอร์เน็ต

**ให้เป็นวิทยาทานแก่ทุกคน** — Phai ERP แจกฟรีเพื่อให้ทุกคนได้เรียนรู้ว่า ERP คืออะไร ทุกหน้าจอมีคำแนะนำว่าเอกสารนี้มาจากไหน ไปต่อที่ไหน และลงบัญชีอย่างไร ใช้ไปก็เข้าใจไป และคิดเป็นระบบได้ เพราะงานในบริษัทต่อเนื่องกันทั้งหมด

*Open-source Thai ERP for small and medium businesses: purchasing, inventory, production, sales, accounting with Thai VAT and withholding tax, e-Tax Invoice, electronic document signing and an AI assistant. Plain PHP, no build step, works offline. English docs: [install](docs/install.en.md) · [user guide](docs/usage.en.md).*

## จุดเด่น

### สร้างมาให้ทุกคนเข้าใจ ERP และคิดเป็นระบบ

Phai ERP เขียนขึ้นเป็นวิทยาทาน ให้เจ้าของกิจการ พนักงาน ครู และนักศึกษาที่ไม่เคยใช้ ERP มาก่อน **เข้าใจว่า ERP คืออะไร และคิดเป็นระบบ** — เพราะงานในบริษัทต่อเนื่องกันทั้งสาย ใบขอซื้อกลายเป็นใบสั่งซื้อ รับของเข้าคลัง ตั้งหนี้ จ่ายเงิน และลงบัญชี โดยไม่ต้องพิมพ์ซ้ำ เมื่อเห็นภาพทั้งสาย ทุกคนจะรู้ว่างานของตัวเองมาจากใคร และส่งต่อให้ใคร ระบบจึงช่วยสอนไปพร้อมกับการใช้งานจริง:

- **มีคำแนะนำทุกหน้าจอ:** ปุ่ม **?** ข้างชื่อผู้ใช้เปิดคำอธิบายของหน้านั้นทันที ครบทุกหน้า ทั้งภาษาไทยและอังกฤษ
- **รู้เสมอว่าอยู่ตรงไหนของระบบ:** ทุกคำอธิบายบอกว่าเอกสารนี้ **มาจาก** เอกสารไหน **ไปต่อ** ที่ไหน ชื่อเอกสารทางราชการคืออะไร และ **ลงบัญชี** อย่างไร
- **หน้า "เรียนรู้ ERP":** ERP คืออะไร, แผนผังโมดูล, สายเอกสารจัดซื้อ (Procure-to-Pay), ขาย (Order-to-Cash), ผลิต (Plan-to-Produce) ทีละขั้นพร้อมรายการบัญชี และอภิธานศัพท์
- **ระบบบอกว่าต้องทำอะไรต่อ:** แต่ละหน้ามีคิวงานแสดงเอกสารของขั้นก่อนหน้าที่รอหน้านี้อยู่ กดเดียวก็ทำขั้นถัดไปได้ — ทำตามคิวไปก็เห็นทั้งสายเอกสาร
- **มีบริษัทตัวอย่างให้ลอง:** โรงงานสมมติย้อนหลัง 2 เดือน ทุกเมนูมีข้อมูล ลองกด ลองพิมพ์ ลองดูงบได้โดยไม่กลัวพัง
- **ถามเป็นภาษาคนได้:** ผู้ช่วย AI ตอบจากข้อมูลจริงในระบบ เช่น "เดือนนี้ขายได้เท่าไร" หรือ "ใครค้างจ่ายบ้าง"

### มีแค่ PHP กับ MySQL — ทำไม

ERP คือระบบที่บริษัทใช้ไปอีกสิบปี จึงต้องติดตั้งได้ทุกที่ ดูแลง่าย และไม่พังเพราะของที่คนอื่นเปลี่ยน

- **ติดตั้งได้ทุกที่:** เว็บโฮสติ้งราคาถูก, เครื่อง Windows ในออฟฟิศ (เช่น Monrak Desktop Server), มินิพีซี RAM 1 GB หรือ VPS — ที่ไหนมี PHP กับ MySQL/MariaDB ก็ใช้ได้ วางไฟล์แล้วเปิดเว็บ หน้าติดตั้งทำที่เหลือให้
- **ไม่มีชิ้นส่วนให้พัง:** ไม่ต้องมี Node.js, Redis, คิวงาน, Docker หรือโปรแกรมที่ต้องรันค้างไว้ เครื่องรีบูตแล้วก็ใช้ต่อได้เลย
- **สำรองข้อมูลง่าย:** ทุกอย่างอยู่ในฐานข้อมูลเดียวกับโฟลเดอร์ `storage/uploads` — สำรองสองอย่างนี้ก็ย้ายเครื่องได้ทั้งบริษัท
- **ใช้ได้โดยไม่ต่ออินเทอร์เน็ต:** CSS, ไอคอน, ฟอนต์ และตัวแสดง PDF อยู่ในโปรเจกต์ทั้งหมด ไม่โหลดจาก CDN — เน็ตล่มก็ยังเปิดบิลได้

### ไม่ใช้เฟรมเวิร์ก — ทำไม

- **คนที่รู้ PHP อย่างเดียวแก้ได้:** ไม่ต้องเรียน Laravel หรือ Symfony ก่อน route คือ attribute บนเมธอด (`#[Get('/api/x')]`), SQL เป็น prepared statement ที่อ่านตรง ๆ ไม่มีเวทมนตร์ซ่อนอยู่
- **ไม่มี dependency ให้ตามอัปเดต:** ไม่มี Composer, npm หรือขั้นตอน build ไม่ต้องอัปเกรดเฟรมเวิร์กทุกสองปี และไม่ต้องกลัวแพ็กเกจของคนอื่นถูกยึดแล้วฝังโค้ดร้าย (supply chain attack)
- **แกนกลางเล็ก มีแค่ที่ ERP ต้องใช้:** ราว 6,000 บรรทัด (`src/Core`) — Router, ตรวจข้อมูล, Model ที่บันทึกประวัติแก้ไขใน transaction เดียวกัน, สิทธิ์ต่อหน้าจอ, เลขที่เอกสาร, PDF — อ่านจบได้ในวันเดียว
- **เร็วและกินเครื่องน้อย:** ไม่มีชั้นที่ไม่จำเป็น ทั้งระบบ zip แล้วไม่ถึง 4 MB

### ที่เขียนเองแทนการลงโปรแกรมเพิ่ม

แทนที่จะให้ผู้ติดตั้งลงเครื่องมือเพิ่ม ส่วนที่ปกติต้องพึ่งของภายนอกถูกเขียนเป็น PHP/JavaScript ในโปรเจกต์ ทำงานเหมือนกันทั้งบน Windows และ Linux:

| ส่วน | แทน |
|---|---|
| **PdfKit** อ่าน รวม ประทับ และย่อ PDF | qpdf, pdftk, Ghostscript |
| **PdfA** แปลงใบกำกับภาษีเป็น PDF/A-3 (ตรวจผ่าน veraPDF) | ไลบรารี PDF/A เชิงพาณิชย์ |
| **Xades** ลงลายมือชื่อ XML e-Tax แบบ XAdES-BES (ตรวจกับ XSD/Schematron ทางการ) | ชุดเครื่องมือ Java/.NET |
| **Mail** ส่งอีเมลผ่าน SMTP | PHPMailer |
| **Qr** QR code เป็น SVG | ไลบรารี QR |
| **BahtText** จำนวนเงินเป็นตัวอักษรภาษาไทย | — |
| **xlsx.js** ส่งออก/นำเข้า Excel ในเบราว์เซอร์ | SheetJS, PhpSpreadsheet |
| **phai.js** ตาราง ฟอร์ม ช่องเลือกแบบค้นหาได้ เรียก API | jQuery, React, Vue |
| ผู้ช่วย AI เรียก Claude / Gemini ด้วย HTTP ตรง | SDK ของผู้ให้บริการ |

PDF ของเอกสารสร้างด้วย Edge/Chrome ที่มีบนเครื่องอยู่แล้ว (หรือ `phai-pdf` บน Phai Server) — ไม่มีก็ยังพิมพ์จากเบราว์เซอร์ได้

### ถูกต้องแบบบัญชีและภาษีไทย

- **ข้อมูลเชื่อมกันทั้งระบบ:** ทุกเอกสารลงสต็อก ต้นทุน และบัญชีแยกประเภทให้เองใน transaction เดียว ไม่ต้องบันทึกซ้ำ ยอดตรงกันทุกหน้า
- **ตรวจสอบย้อนหลังได้ทุกรายการ:** ทำขั้นถัดไปแล้ว เอกสารต้นทางแก้หรือยกเลิกไม่ได้ ยกเลิกคือกลับรายการ ไม่ลบของเดิม ปิดงวดแล้วลงย้อนไม่ได้
- **แบบฟอร์มราชการตามจริง:** 50 ทวิ, ภ.ง.ด.3/53 (แบบยื่นและใบแนบ), ภ.พ.30, รายงานภาษีซื้อ/ขาย, รายงานสินค้าและวัตถุดิบ ม.87(3), ภาษีขายของงานบริการตาม ม.78/1
- **e-Tax Invoice ครบสองแบบ:** by Email (PDF/A-3) และไฟล์ XML ตาม ขมธอ.3-2560 ลงนามแล้ว

### ไว้ใจได้

- **ตรวจสอบได้ว่าใครทำอะไร:** ทุกตารางบันทึกผู้สร้าง/ผู้แก้ ประวัติแก้ไขทุกแถว (`audit_log`) ผู้ใช้ปิดได้แต่ไม่ลบ
- **สิทธิ์ชุดเดียวทุกทาง:** สิทธิ์ต่อหน้าจอ (ดู เพิ่ม แก้ ลบ พิมพ์) ใช้กับหน้าเว็บ, API และผู้ช่วย AI เหมือนกัน AI อ่านได้เฉพาะสิ่งที่ผู้ถามเห็น และแก้ข้อมูลไม่ได้
- **ความปลอดภัย:** CSRF ทุกคำขอที่แก้ข้อมูล, ล็อกเมื่อใส่รหัสผิดซ้ำ, ออกจากระบบเมื่อไม่ใช้งาน ดู [SECURITY.md](SECURITY.md)
- **ทดสอบทั้งระบบทุกครั้ง:** เทสต์ราว 940 ข้อติดตั้งระบบใหม่ผ่านหน้าติดตั้งจริงทุกชุด ทำเอกสารครบทุกสาย และลองเรียกทั้ง 663 route ด้วยผู้ใช้ที่ไม่มีสิทธิ์ (ต้องได้ 403 ทุกอัน) รวม SQL injection, XSS และการเข้าถึงไฟล์

### ใช้ง่ายและเป็นของคุณ

- **ข้อมูลอยู่ในบริษัท ไม่มีค่าสมาชิก:** สัญญาอนุญาต MIT ใช้ แก้ แจกต่อได้ รวมถึงเชิงพาณิชย์
- **หน้าจอเรียบ ทำงานต่อได้ทันที:** คิวงานบอกว่ามีเอกสารอะไรรอหน้านี้อยู่, ทุกหน้ามีคำอธิบาย (ปุ่ม ?) และหน้า "เรียนรู้ ERP" ไทย/อังกฤษ ใบพิมพ์เป็นภาษาไทยเสมอ
- **ทุกหน้าจอมี JSON API คู่กัน:** โปรแกรมอื่นเรียก API ชุดเดียวกับหน้าเว็บได้
- **ลายเซ็นในเอกสาร:** ขอให้เซ็นและอนุมัติบนใบพิมพ์ได้เลย พร้อมระบบส่งเอกสาร PDF ให้คนนอกเซ็น
- **ข้อมูลตัวอย่าง:** ติ๊กตอนติดตั้ง หรือสั่ง `php bin/phai demo` ได้โรงงานสมมติที่ทุกเมนูมีข้อมูลให้ลอง

## ใช้ฟรีทุกฟีเจอร์ หรือให้เราวางระบบให้

เหมาะกับ **บริษัทเล็กถึงกลาง** ที่อยากได้ระบบงานครบชุดในราคาศูนย์บาท ติดตั้งบนเครื่องในออฟฟิศเครื่องเดียว ใช้ได้ทั้งแบบต่อและไม่ต่ออินเทอร์เน็ต ข้อมูลอยู่ในบริษัทของคุณเอง ไม่มีค่าสมาชิกรายเดือน ไม่จำกัดจำนวนผู้ใช้

- **ทำเอง ฟรี:** ดาวน์โหลด ติดตั้งตาม [คู่มือ](docs/install.th.md) ไม่กี่นาทีก็เริ่มเปิดบิลได้
- **ให้มืออาชีพวางระบบ:** บริการจาก Monrak Net ([monrak.net](https://www.monrak.net/))
  1. **วางระบบ (implement) ให้เข้ากับงานจริงของบริษัทคุณ** — ศึกษางาน จับคู่เข้ากับสายเอกสาร ตั้งผังบัญชี สินค้า สูตรการผลิต สิทธิ์ผู้ใช้ ย้ายข้อมูลและยอดยกมา จนเริ่มใช้จริงได้
  2. สอนพนักงานด้วยบริษัทตัวอย่าง และอยู่ด้วยช่วงแรกหลังเริ่มใช้งาน
  3. ติดตั้งพร้อมระบบสำรองข้อมูลอัตโนมัติ
  4. อัปเดตรุ่นเมื่อกฎหมายภาษีเปลี่ยน และดูแลเมื่อเครื่องมีปัญหา
  5. ปรับแต่งเพิ่มเติมตามธุรกิจของคุณ

## ความต้องการของระบบ

| | ขั้นต่ำ |
|---|---|
| PHP | 8.2 ขึ้นไป พร้อม `pdo_mysql` และ `mbstring` (`curl` ถ้าจะใช้ AI หรือบริการ Phai Sign) |
| ฐานข้อมูล | MySQL หรือ MariaDB |
| เว็บเซิร์ฟเวอร์ | Apache (มี `.htaccess` ให้) หรือเว็บเซิร์ฟเวอร์ใดก็ได้ที่ชี้ไปที่ `public/` |
| สร้าง PDF | Microsoft Edge หรือ Google Chrome บนเครื่องเซิร์ฟเวอร์ หรือ `phai-pdf` บน Phai Server |

## เริ่มใช้

1. วางโฟลเดอร์ไว้ใต้ web root หรือชี้เว็บเซิร์ฟเวอร์ไปที่ `public/`
2. เปิดเว็บ ระบบจะพาไปหน้าติดตั้ง 5 ขั้น: ตรวจเครื่อง, ฐานข้อมูล, บริษัท (โลโก้และที่อยู่), ผู้ดูแลระบบ, ยืนยัน ติ๊ก **ใส่ข้อมูลตัวอย่าง** ถ้าต้องการลองใช้
3. เข้าสู่ระบบด้วยผู้ดูแลที่ตั้งไว้

บน Phai Server ไม่ต้องทำขั้นตอนนี้ ตัวติดตั้งของเครื่องถามชื่อบริษัทและผู้ดูแลระบบ แล้วติดตั้ง Phai ERP ให้ตอนบูตครั้งแรก

รายละเอียด: [คู่มือติดตั้ง](docs/install.th.md) · [คู่มือการใช้งาน](docs/usage.th.md) · [e-Tax Invoice](docs/etax-invoice.th.md)

## คำสั่งบนเครื่องเซิร์ฟเวอร์

```bash
php bin/phai version                 # รุ่นของระบบ
php bin/phai demo                    # ใส่ข้อมูลตัวอย่างในระบบที่ยังว่าง
php bin/phai password <ผู้ใช้>         # ตั้งรหัสผ่านใหม่ เมื่อผู้ใช้ลืมรหัส
php bin/phai install <setup.json>    # ติดตั้งโดยไม่ผ่านหน้าเว็บ (Phai Server ใช้คำสั่งนี้)
php bin/phai esign-sync              # ส่งงานเซ็นของคนนอกไป Phai Sign และดึงผลกลับ (ตั้งให้รันทุก 15 นาที)
```

```bash
php tests/run.php          # unit tests

```

```
public/      จุดเข้าเว็บ, css, js, ฟอนต์ และไลบรารีที่ฝังไว้ (vendor/)

docs/        คู่มือ
ux/          แนวทางหน้าจอ (ui.md)
tests/       unit tests และ e2e
bin/phai     คำสั่งบนเครื่องเซิร์ฟเวอร์
```
