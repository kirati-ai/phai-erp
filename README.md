# Phai ERP

ระบบ ERP ภาษาไทยแบบโอเพนซอร์ส สำหรับธุรกิจขนาดเล็กถึงกลาง ครบตั้งแต่จัดซื้อ คลังสินค้า ผลิต ขาย ไปจนถึงบัญชีและภาษีไทย มีระบบเซ็นเอกสารอิเล็กทรอนิกส์และผู้ช่วย AI ในตัว เขียนด้วย PHP ล้วน ไม่ต้อง build และใช้งานได้โดยไม่ต้องต่ออินเทอร์เน็ต

*Open-source Thai ERP for small and medium businesses: purchasing, inventory, production, sales, accounting with Thai VAT and withholding tax, e-Tax Invoice, electronic document signing and an AI assistant. Plain PHP, no build step, works offline. English docs: [install](docs/install.en.md) · [user guide](docs/usage.en.md).*

Phai ERP เป็นส่วนหนึ่งของ **Phai Suite** ร่วมกับ Phai Server (เครื่องเซิร์ฟเวอร์สำเร็จรูปที่ติดตั้ง Phai ERP ให้เอง) และ Phai Desk (ดูแลคอมพิวเตอร์ Windows ในสำนักงาน) แต่ใช้แยกเดี่ยวบนเว็บเซิร์ฟเวอร์ PHP ทั่วไปก็ได้

## ทำอะไรได้บ้าง

| งาน | สิ่งที่มี |
|---|---|
| **ข้อมูลหลัก** | สินค้าและวัตถุดิบ, กลุ่ม/ประเภท/สายผลิตภัณฑ์, หน่วยนับ, ลูกค้า, ผู้ขาย, สกุลเงินและอัตราแลกเปลี่ยน, ภาษี, เงื่อนไขชำระเงิน, ที่อยู่ไทยแบบเลือกจังหวัด อำเภอ ตำบล |
| **จัดซื้อ** | ใบขอซื้อ, ใบสั่งซื้อพร้อมอนุมัติ, ตารางกำหนดส่งของผู้ขาย, รับสินค้าเข้าคลัง, ค่าใช้จ่ายนำเข้า (landed cost), ส่งคืนสินค้า, ประเมินผู้ขาย |
| **คลังสินค้า** | ยอดคงเหลือตามคลัง ตำแหน่ง และ lot, รับ เบิก ปรับ โอน, ตรวจนับสต็อก, ประวัติความเคลื่อนไหว, ต้นทุนถัวเฉลี่ย, รหัสเหตุผล |
| **ผลิต** | สูตรการผลิต (BOM), ขั้นตอนการผลิต, ศูนย์งาน เครื่องจักร พนักงาน, ใบสั่งผลิต (เบิกวัตถุดิบ ค่าแรง รับสินค้า), ตรวจคุณภาพ (QC), วางแผนวัตถุดิบ (MRP) และวางแผนแยกสาขา |
| **ขาย** | ราคาขาย, ใบเสนอราคา, ใบสั่งขายพร้อมวงเงินเครดิต, ตารางกำหนดส่ง, ใบส่งของ, ใบแจ้งหนี้/ใบกำกับภาษี, ใบวางบิล, รับคืนสินค้า, จำนวนเงินเป็นตัวอักษรภาษาไทย |
| **บัญชีและการเงิน** | ผังบัญชี บัญชีย่อย ศูนย์ต้นทุน, ลงบัญชีอัตโนมัติจากทุกเอกสาร, สมุดรายวันพร้อมกลับรายการ, ลูกหนี้ เจ้าหนี้ ใบสำคัญจ่าย รับเงินมัดจำ, เงินสดย่อย, บัญชีธนาคารและกระทบยอด, สินทรัพย์ถาวรและค่าเสื่อมราคา, งบทดลอง งบการเงิน, ปิดงวด |
| **ภาษีไทย** | รายงานภาษีซื้อ/ขาย, ภ.พ.30, ภาษีหัก ณ ที่จ่ายและหนังสือรับรอง 50 ทวิ, ภ.ง.ด.3/53, **e-Tax Invoice by Email** (PDF/A-3) และไฟล์ XML ลงลายมือชื่อ XAdES-BES สำหรับอัปโหลดเข้าระบบกรมสรรพากร |
| **เอกสารลงนาม (e-Sign)** | ส่ง PDF ให้เซ็นตามลำดับขั้น ทั้งคนในบริษัทและคนนอก (ผ่านบริการ Phai Sign), ตัวแก้วางช่องแบบโปรแกรมแก้ PDF, บันทึกเวลารับ เปิด เซ็น, ฉบับสุดท้ายมี QR code และหน้าหลักฐาน (SHA-256 รายหน้า, ประวัติต่อกันเป็นโซ่ hash), หน้าตรวจเอกสาร |
| **ผู้ช่วย AI** | ถามข้อมูลด้วยภาษาคน (Claude หรือ Gemini) อ่านได้เฉพาะสิ่งที่ผู้ถามมีสิทธิ์เห็น แก้ข้อมูลไม่ได้ และมีบันทึกการใช้และค่าใช้จ่าย |
| **ระบบ** | ผู้ใช้ บทบาท และสิทธิ์ต่อหน้าจอ (ดู เพิ่ม แก้ ลบ พิมพ์ อนุมัติ), ประวัติการแก้ไขทุกรายการ, เมนูปรับได้, เลขที่เอกสารตั้งรูปแบบได้, หลายสาขา, ไฟล์แนบทุกเอกสาร, ลายเซ็นและตราประทับบนเอกสาร, หน้าภาพรวมแต่ละฝ่าย, หน้า "เรียนรู้ ERP", ภาษาไทย/อังกฤษ |

## จุดเด่น

- **ติดตั้งง่าย:** ใช้แค่ PHP กับ MySQL/MariaDB ไม่ต้องมี Composer, npm หรือขั้นตอน build วางไฟล์แล้วเปิดเว็บก็ติดตั้งได้
- **ใช้ได้โดยไม่ต่ออินเทอร์เน็ต:** CSS, ไอคอน, ฟอนต์ และตัวแสดง PDF อยู่ในโปรเจกต์ทั้งหมด ไม่โหลดจาก CDN
- **ทุกหน้าจอมี JSON API คู่กัน:** หน้าเว็บเรียก API เดียวกับที่โปรแกรมอื่นใช้ได้
- **ข้อมูลเชื่อมกันทั้งระบบ:** สต็อก ต้นทุน และบัญชีแยกประเภทลงให้เองจากเอกสาร ไม่ต้องบันทึกซ้ำ
- **PDF จริงจากเซิร์ฟเวอร์:** ใช้ Edge/Chrome บน Windows หรือ `phai-pdf` (WebKit) บน Phai Server ส่วนการรวมและประทับ PDF ของเอกสารลงนามใช้ไลบรารี PHP ที่เขียนเอง (PdfKit) ไม่ต้องพึ่งเครื่องมือภายนอก
- **ความปลอดภัย:** ตรวจสิทธิ์และ CSRF ทุก route, ล็อกเมื่อเข้าสู่ระบบผิดซ้ำ, มีชุดทดสอบความปลอดภัยอัตโนมัติ (SQL injection, XSS, การเข้าถึงไฟล์, session) ดู [SECURITY.md](SECURITY.md)
- **ข้อมูลตัวอย่าง:** ติ๊กตอนติดตั้ง หรือสั่ง `php bin/phai demo` เพื่อทดลองใช้

## ความต้องการของระบบ

| | ขั้นต่ำ |
|---|---|
| PHP | 8.2 ขึ้นไป พร้อม `pdo_mysql` และ `mbstring` (`curl` ถ้าจะใช้ AI หรือบริการ Phai Sign) |
| ฐานข้อมูล | MySQL หรือ MariaDB |
| เว็บเซิร์ฟเวอร์ | Apache (มี `.htaccess` ให้) หรือเว็บเซิร์ฟเวอร์ใดก็ได้ที่ชี้ไปที่ `public/` |
| สร้าง PDF | Microsoft Edge หรือ Google Chrome บนเครื่องเซิร์ฟเวอร์ หรือ `phai-pdf` บน Phai Server |

## เริ่มใช้

1. วางโฟลเดอร์ไว้ใต้ web root หรือชี้เว็บเซิร์ฟเวอร์ไปที่ `public/`
2. เปิดเว็บ ระบบจะพาไปหน้าติดตั้ง 5 ขั้น: ตรวจเครื่อง, ฐานข้อมูล, บริษัท (โลโก้และที่อยู่), ผู้ดูแลระบบ, ยืนยัน ติ๊ก **ใส่ข้อมูลตัวอย่าง** ถ้าต้องการลองใช้
3. เข้าสู่ระบบด้วยผู้ดูแลที่ตั้งไว้

บน Phai Server ไม่ต้องทำขั้นตอนนี้ ตัวติดตั้งของเครื่องถามชื่อบริษัทและผู้ดูแลระบบ แล้วติดตั้ง Phai ERP ให้ตอนบูตครั้งแรก

## คำสั่งบนเครื่องเซิร์ฟเวอร์

```bash
php bin/phai version                 # รุ่นของระบบ
php bin/phai demo                    # ใส่ข้อมูลตัวอย่างในระบบที่ยังว่าง
php bin/phai password <ผู้ใช้>         # ตั้งรหัสผ่านใหม่ เมื่อผู้ใช้ลืมรหัส
php bin/phai install <setup.json>    # ติดตั้งโดยไม่ผ่านหน้าเว็บ (Phai Server ใช้คำสั่งนี้)
php bin/phai esign-sync              # ส่งงานเซ็นของคนนอกไป Phai Sign และดึงผลกลับ (ตั้งให้รันทุก 15 นาที)
```

## สำหรับนักพัฒนา

```bash
php tests/run.php          # unit tests
php tests/e2e/run.php      # ทดสอบทั้งระบบผ่านเว็บ รวมความปลอดภัย (สร้างฐานข้อมูลทดสอบแยก ไม่แตะระบบที่ใช้งานอยู่)
```

```
public/      จุดเข้าเว็บ, css, js, ฟอนต์ และไลบรารีที่ฝังไว้ (vendor/)
src/Core/    แกนกลาง "Phai Core": Http, Routing, Db, Validation, Auth, View, Audit, Ai, Pdf, PdfA, PdfKit, Xades, Qr, Mail
src/Modules/ โมดูลธุรกิจ: Master, Purchase, Inventory, Production, Sales, Accounting, Esign, System
src/Install/ ตัวติดตั้งและข้อมูลตัวอย่าง
views/       หน้าจอ
lang/        ไฟล์ภาษา (th, en)
database/    schema (125 ตาราง) และข้อมูลตั้งต้น
docs/        คู่มือ
ux/          แนวทางหน้าจอ (ui.md)
tests/       unit tests และ e2e
bin/phai     คำสั่งบนเครื่องเซิร์ฟเวอร์
```

แนวทางการเขียนโค้ดอยู่ใน [CLAUDE.md](CLAUDE.md), แนวทางหน้าจอใน [ux/ui.md](ux/ui.md) และแผนพัฒนาใน [PHAIERP_PLAN.md](PHAIERP_PLAN.md)
